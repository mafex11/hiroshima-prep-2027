What these are, and why they matter to you

These are the official written entrance papers of the Informatics and Data Science Program (情報科学プログラム), general selection. Your selection has no written exam. But these papers show what this faculty calls "basic knowledge", and Prof. Zheng said maths questions in your oral exam "depend on the committee". If a committee member asks you a maths question aloud, it will most likely be at this level and on these topics.

All six recent papers are public and are saved in past_papers/. Each paper is printed in Japanese and English side by side, so the English below follows the official wording, lightly shortened. Format of every paper:

  • Specialized Subject I (専門科目I), 9:00 to 11:00. Answer all four questions: linear algebra, calculus, probability, discrete maths.
  • Specialized Subject II (専門科目II), 13:30 to 15:30. Choose three of Questions 1 to 6 (information theory, algorithms and data structures, C programming, digital circuits, statistics, machine learning), and also answer Question 7 (a short research summary).

This file covers the three most recent papers in full: January 2026, August 2025, January 2025. The topic table at the end covers all six papers plus an older sample booklet.

Official model answers exist for January 2026 and August 2025 (「解答又は解答例等及び出題の意図」). For those, my answers were checked against the official ones. Paper 1: January 2026 (official answers published)

Subject I

Q1. Linear algebra: rank and null space

Question. A is a nonzero real 2×4 matrix. True or false? If true, give a reason. If false, give a counterexample.

  1. The rank of A is at least 2.
  2. The null space of A has dimension at least 2.
  3. Ax = 0 has exactly one solution.
  4. The two rows of A are always linearly independent.
  5. There are linearly independent vectors v and w with Av = Aw = 0.

Solution.

  1. False. A = [[1,0,0,0],[1,0,0,0]] is nonzero with rank 1.
  2. True. Rank-nullity: dim ker A = 4 − rank A. Rank is at most 2 (only two rows), so dim ker A ≥ 2.
  3. False. The null space has dimension at least 2, so there are infinitely many solutions. With the matrix above, x = (0,1,0,0) is a nonzero solution.
  4. False. Same matrix: the rows are equal.
  5. True. Take two vectors from a basis of the null space, which has dimension at least 2.

Say it out loud. "A 2×4 matrix maps R⁴ to R², so its rank is at most 2, and rank-nullity says the null space has dimension at least 4 minus 2, which is 2. That one fact settles (2), (3) and (5)."

Q2. Calculus: minimum on a region and a double integral

Question. f(x, y) = x² − 2x cos y − cos 2y + 2, on D = {0 ≤ x, 0 ≤ y, x + y ≤ π/2}.

  1. Find the minimum of f on D.
  2. Evaluate I = ∬_D |f(x, y)| dx dy.

Solution.

  1. Complete the square. Since cos 2y = 1 − 2 sin² y and cos² y = 1 − sin² y: f = (x − cos y)² − cos² y − cos 2y + 2 = (x − cos y)² + 3 sin² y. Both terms are ≥ 0. f = 0 needs sin y = 0 and x = cos y, so y = 0, x = 1. The point (1, 0) is in D because 1 ≤ π/2. Minimum 0 at (1, 0).
  2. Since f ≥ 0, |f| = f. Integrate in y first, with L = π/2 − x: ∫₀ᴸ f dy = x²L − 2x sin L − ½ sin 2L + 2L. Here sin L = cos x and sin 2L = sin 2x, so this is (π/2)x² − x³ − 2x cos x − ½ sin 2x + π − 2x. Now integrate from 0 to a = π/2:
    • ∫ (a x² − x³) dx = a⁴/12 = π⁴/192
    • ∫ −2x cos x dx = −2[x sin x + cos x]₀ᵃ = −2(a − 1) = 2 − π
    • ∫ −½ sin 2x dx = [¼ cos 2x]₀ᵃ = −½
    • ∫ (π − 2x) dx = πa − a² = π²/4 I = π⁴/192 + π²/4 − π + 3/2 ≈ 1.333. This matches the official answer and a numeric check.

Say it out loud. "I'd first write f as a sum of squares, (x − cos y)² + 3 sin² y. That shows f is never negative, so the minimum is 0 at (1, 0), and the absolute value in the integral does nothing."

Q3. Probability: gamma and Pareto distributions

Question. X ~ Gamma with shape α > 0, scale β > 0: f_X(x) = x^(α−1) e^(−x/β) / (Γ(α) β^α), x > 0. T has pdf f_T(t) = ν t^(−ν−1), t > 1, ν > 0. You may use Γ(α+1) = αΓ(α).

  1. Find E[X]. 2. Find Var[X]. 3. Find the gamma pdf with E[X] = 1 and Var[X] = η (η > 0). 4. Find E[T] for ν = 1, if it exists. 5. Find E[T] for ν = 3, if it exists.

Solution.

  1. E[X] = ∫ x f dx = Γ(α+1)β^(α+1) / (Γ(α)β^α) = αβ.
  2. E[X²] = Γ(α+2)β² / Γ(α) = α(α+1)β². Var = α(α+1)β² − α²β² = αβ².
  3. αβ = 1 and αβ² = η give β = η, α = 1/η. So f(x) = x^(1/η − 1) e^(−x/η) / (Γ(1/η) η^(1/η)), x > 0.
  4. E[T] = ∫₁^∞ t · t⁻² dt = ∫₁^∞ dt/t, which diverges. E[T] does not exist.
  5. E[T] = ∫₁^∞ 3 t⁻³ dt = 3 · ½ = 3/2.

Say it out loud. "For the gamma, I use the trick that the integral of x^(α) e^(−x/β) is Γ(α+1)β^(α+1), so the mean is αβ and the variance αβ². For the Pareto, the mean exists only when ν > 1, because otherwise the tail decays like 1/t and the integral diverges."

Why this one matters for you: the gamma distribution and heavy tails come up in software reliability (failure times, Bayesian priors). Know (1), (2) and (4) cold.

Q4. Discrete maths: relations, counting, quantifiers

Question. A = {1,2,3,4,5}, R = {(x, y) | x ≤ y} ⊆ A × A.

  1. Is R reflexive, symmetric, transitive? Justify each.
  2. Give R as an adjacency matrix and draw the directed graph (need not be simple).
  3. Choose 3 elements of A. (a) How many subsets? (b) How many if the largest element must be 5?
  4. Write ∀x ∈ A, ∃y ∈ A, (x ≤ y) in predicate logic, decide if it is true, and prove it.

Solution.

  1. Reflexive: yes, x ≤ x. Symmetric: no, (1,2) ∈ R but (2,1) ∉ R. Transitive: yes, x ≤ y and y ≤ z give x ≤ z. (It is also antisymmetric, so it is a partial order, in fact a total order.)
  2. M[i][j] = 1 if i ≤ j. So M is the 5×5 upper triangular matrix of ones (ones on and above the diagonal). The graph has a self-loop at every vertex and an edge i → j for every i < j: 15 edges in total.
  3. (a) C(5,3) = 10. (b) 5 must be in, choose 2 more from {1,2,3,4}: C(4,2) = 6.
  4. ∀x (x ∈ A → ∃y (y ∈ A ∧ x ≤ y)). True. For any x, take y = x (or y = 5).

Say it out loud. "≤ is reflexive and transitive but not symmetric, so it's an order, not an equivalence. For counting with the maximum fixed at 5, I fix 5 and choose the other two from the four smaller numbers."

Subject II

Q1. Information theory: entropy of a source and its extension

Question. Memoryless source U: u1, u2, u3 with probabilities 1/2, 1/3, 1/6. Use log₂3 ≈ 1.6.

  1. What is a memoryless information source? 2. Compute H(U). 3. Find the probabilities of (u1,u2), (u2,u1), (u3,u3) in the second extension U². 4. Compute H(U²).

Solution.

  1. Each symbol is produced independently of the earlier symbols (the probabilities do not depend on the past).
  2. H(U) = ½·1 + ⅓·log₂3 + ⅙·(1 + log₂3) = ⅔ + ½ log₂3 ≈ 0.667 + 0.8 = 1.467 bits. (Exact value 1.459.)
  3. By independence: (u1,u2) = ½·⅓ = 1/6 ≈ 0.167; (u2,u1) = 1/6 ≈ 0.167; (u3,u3) = 1/36 ≈ 0.0278.
  4. For a memoryless source, H(U²) = 2H(U) ≈ 2.934 bits.

Say it out loud. "Because the source has no memory, pairs are independent, so joint probabilities multiply and the entropy of the pair is twice the entropy of one symbol."

Q2. Data structures: max-heap priority queue

Question. A max-heap stored in A[1..n], m elements, left(i) = 2i, right(i) = 2i+1, parent(i) = ⌊i/2⌋, with A[parent(i)] ≥ A[i]. Insert puts x at A[m+1] and moves it up. Extract-Max removes the root, moves the last element to the root and moves it down. Update-Key(Q, i, k) raises the key at position i to k (k ≥ old value) and moves it up.

  1. Insert 5, 10, 2, 9, 6 into an empty heap. Show the array after each insert.
  2. Run Extract-Max once on the result. 3. Run Update-Key(Q, 3, 11) on the result of (1). 4. Give the Big-O cost of each operation and why. 5. Show that any subtree rooted at position i is also a heap.

Solution.

  1. [5] → [10,5] → [10,5,2] → [10,9,2,5] (9 swaps with 5) → [10,9,2,5,6].
  2. Remove 10, move 6 to the root: [6,9,2,5]; 6 < 9, swap: [9,6,2,5].
  3. Set A[3] = 11: [10,9,11,5,6]; 11 > parent 10, swap: [11,9,10,5,6].
  4. All three are O(log m): each one moves one element along a single root-to-leaf path, and a complete binary tree with m nodes has height ⌊log₂ m⌋.
  5. Every node j in the subtree at i, other than i itself, has its parent inside the same subtree. The heap condition A[parent(j)] ≥ A[j] holds for all j in the whole heap, so it holds for all j in the subtree.

Say it out loud. "A heap only promises that each parent beats its children, so every update just walks one path of length log m."

Q3. C programming: circular queue

Question. A circular queue in an int array. Queue has data, capacity, front (first element), rear (one past the last), size. Fill the blanks, trace the output, and redesign the full test.

int init(Queue *q, int cap) {
    q->data = malloc([1-1] * cap);
    if (q->data == NULL) return 0;
    q->capacity = cap;
    q->front = q->rear = [1-2] = 0;
    return 1;
}
int enqueue(Queue *q, int x) {           /* 1 on success, 0 if full */
    if ([1-3]) return 0;
    q->data[[1-4]] = x;
    q->rear = [1-5];
    q->size++;
    return 1;
}
int dequeue(Queue *q, int *out) {        /* 1 on success, 0 if empty */
    if (q->size == 0) return 0;
    *out = q->data[[1-6]];
    q->front = [1-7];
    q->size--;
    return 1;
}
/* main: init(&q, 5); print; enqueue 10, 20, 30; dequeue; print "Current";
   enqueue 40, 50; dequeue; enqueue 60, 70; print "Final"; free([1-8]); */

Output: Initial: front=0, rear=0, size=0 / Current: front=[2-1], rear=3, size=2 / Final: front=2, rear=[2-2], size=5.

  1. Why is it called circular? (A) the array is reallocated and rearranged when full; (B) when rear reaches the end it wraps to the start, so the whole array is used in a circle; (C) the contents are rotated on each enqueue.
  2. Fill 1-1 to 1-8, using size to test empty and full. 3. Fill 2-1 and 2-2. 4. Without size, keeping one slot always empty, rewrite the full test in 1-3, and give 2-2 under that rule.

Solution.

  1. B.
  2. 1-1 sizeof(int); 1-2 q->size; 1-3 q->size == q->capacity; 1-4 q->rear; 1-5 (q->rear + 1) % q->capacity; 1-6 q->front; 1-7 (q->front + 1) % q->capacity; 1-8 q.data.
  3. After 10, 20, 30: front 0, rear 3, size 3. Dequeue: front 1 (2-1). Then 40 → rear 4; 50 → rear 0; dequeue → front 2; 60 → rear 1; 70 → rear 2 (2-2), size 5.
  4. Full test: (q->rear + 1) % q->capacity == q->front. Now the queue holds at most 4. Tracing: after 60, rear = 1 and front = 2, so (1+1) % 5 = 2 = front: 70 is refused. 2-2 = 1. (Official answer: 1. Equivalent forms of the condition were accepted.)

Say it out loud. "Front and rear move forward modulo the capacity, so the array is reused in a ring. Without a size counter, empty and full would both look like front equals rear, so we sacrifice one slot to tell them apart."

Q4. Digital circuits: full adder and adder-subtractor

Question. A full adder (FA) takes x, y, c_in and gives s, c_out. X = X3..X0 and Y = Y3..Y0 are 4-bit two's complement numbers, Z = Z4..Z0 is 5-bit two's complement.

  1. Build an FA from XOR, AND and OR only. 2. Build Z = X + Y from four FA blocks. 3. Build Z = X − Y from four FA blocks and NOT gates. 4. Build an adder-subtractor: Z = X + Y if Q = 1, Z = X − Y if Q = 0, from FA blocks, XOR and NOT only.

Solution.

  1. s = x ⊕ y ⊕ c_in (two XOR gates). c_out = (x·y) + (c_in·(x ⊕ y)) (two AND, one OR, reusing x ⊕ y).
  2. Ripple-carry: FA_i adds X_i, Y_i and the carry c_(i−1); FA_0 gets c_in = 0. Z_i = s_i for i = 0..3. The official figure takes Z4 = c3, the carry out of the top adder. [CHECK] For two's complement inputs, the correct fifth bit is the sign-extended sum, Z4 = X3 ⊕ Y3 ⊕ c3. Taking Z4 = c3 is right only for unsigned numbers. My Python check over all 256 input pairs found Z4 = c3 gives the wrong signed result in 128 of them, for example X = −1 (1111), Y = 1 (0001): the low bits are 0000 and c3 = 1, so Z = 10000 = −16, not 0. With only four FA blocks and no extra gates, the official answer is the intended one. If asked aloud, mention the sign-extension point.
  3. X − Y = X + (NOT Y) + 1. Put a NOT on each Y_i and set FA_0's c_in = 1.
  4. Feed Y_i ⊕ Q̄ into FA_i and set c_in = Q̄ (one NOT on Q, four XOR). If Q = 1, Q̄ = 0: Y passes and c_in = 0, so X + Y. If Q = 0, Q̄ = 1: each Y_i is inverted and c_in = 1, so X − Y. This matches the official figure.

Say it out loud. "Subtraction in two's complement is adding the bitwise inverse plus one, so an XOR with the control bit inverts Y on demand, and the same control bit supplies the plus one as the first carry-in."

Q5. Statistics: MLE for the uniform distribution

Question. X1..Xn iid Uniform[0, θ], θ > 0 unknown.

  1. Write the likelihood L(θ). 2. Show the MLE is θ̂ = max(X1..Xn). 3. Show θ̂ has pdf n x^(n−1)/θⁿ on [0, θ]. 4. Show E[θ̂] = nθ/(n+1).

Solution.

  1. Each density is 1/θ on [0, θ]. So L(θ) = θ⁻ⁿ if max Xi ≤ θ, and 0 otherwise.
  2. On the allowed range θ ≥ max Xi, θ⁻ⁿ decreases in θ. So L is largest at the smallest allowed θ: θ̂ = max Xi. (Setting a derivative to zero does not work here, because the maximum is at the edge of the range.)
  3. P(θ̂ ≤ x) = P(all Xi ≤ x) = (x/θ)ⁿ for 0 ≤ x ≤ θ. Differentiate: n x^(n−1)/θⁿ.
  4. E[θ̂] = ∫₀^θ x · n x^(n−1)/θⁿ dx = (n/θⁿ) · θ^(n+1)/(n+1) = nθ/(n+1). So the MLE is biased low; (n+1)/n · max Xi is unbiased.

Say it out loud. "The likelihood is zero until θ passes the largest observation, then it falls like 1 over θ to the n, so the peak is exactly at the maximum. It is biased, because the true θ is always at least the largest sample."

Q6. Machine learning: Bayes decision with a loss function

Question. Two classes, priors P(ω1) = 0.6, P(ω2) = 0.4. Loss λ(ωi | ωj) for deciding ωi when the truth is ωj: λ(ω1|ω1) = 0, λ(ω2|ω1) = 1, λ(ω1|ω2) = 2, λ(ω2|ω2) = 0. An observation x has P(x|ω1) = 0.8, P(x|ω2) = 0.3.

  1. Find P(ω1|x) and P(ω2|x). 2. Find the conditional risks R(ω1|x), R(ω2|x) and decide the class. 3. Change λ(ω1|ω2) from 2 to 5. Recompute. Does the decision change? 4. Explain the link between conditional risk and the loss function in about 100 words.

Solution.

  1. P(x) = 0.8·0.6 + 0.3·0.4 = 0.60. P(ω1|x) = 0.48/0.60 = 0.8, P(ω2|x) = 0.12/0.60 = 0.2.
  2. R(ωi|x) = Σj λ(ωi|ωj) P(ωj|x). R(ω1|x) = 0·0.8 + 2·0.2 = 0.4. R(ω2|x) = 1·0.8 + 0·0.2 = 0.8. Choose the smaller risk: ω1.
  3. R(ω1|x) = 5·0.2 = 1.0, R(ω2|x) = 0.8 unchanged. Now ω2 has lower risk, so the decision changes.
  4. The conditional risk of a decision is its expected loss given x: the posterior probabilities weighted by what each mistake costs. The Bayes rule picks the decision with the smallest risk. So the loss function moves the decision boundary: making one kind of mistake more expensive makes the classifier avoid it, even against the more probable class. With 0-1 loss this reduces to picking the class with the largest posterior.

Say it out loud. "Here x is four times more likely to be class 1, but if wrongly calling something class 1 costs 5, it's safer to say class 2. The loss decides, not just the probability."

Paper 2: August 2025 (official answers published)

Subject I

Q1. Linear algebra: the all-ones matrix

Question. A is the 4×4 all-ones matrix. B has 2 on the diagonal and −1 elsewhere.

  1. Rank and eigenvalues of A. 2. Rank and eigenvalues of B. 3. Show B is invertible; find det(B⁻¹) and the eigenvalues of B⁻¹. 4. Show AB = BA and find (AB)ᵏ for k ≥ 1.

Solution.

  1. All rows are equal, so rank A = 1. Three eigenvalues are 0 (null space has dimension 3). The trace is 4, so the last eigenvalue is 4 (eigenvector (1,1,1,1)). Eigenvalues 4, 0, 0, 0.
  2. B = 3I − A. Same eigenvectors, eigenvalues 3 − λ: −1, 3, 3, 3. No zero eigenvalue, so rank B = 4.
  3. det B = (−1)·3³ = −27 ≠ 0, so B is invertible. B⁻¹ has eigenvalues −1, 1/3, 1/3, 1/3, and det B⁻¹ = −1/27.
  4. A and B = 3I − A are both polynomials in A, so they commute: AB = 3A − A² = BA. Since A² = 4A, AB = 3A − 4A = −A. So (AB)ᵏ = (−A)ᵏ = (−1)ᵏ 4^(k−1) A, the matrix with every entry (−1)ᵏ 4^(k−1).

Say it out loud. "The key is to see B as 3I minus A. Then everything about B comes from A, whose eigenvalues are 4 and three zeros because it's rank one with trace four."

Q2. Calculus: a function defined by an integral

Q5. Statistics: Pearson's chi-square test

Question. A survey of high-school students:

Dislike reading Like reading Total
Dislike Japanese class 20 10 30
Like Japanese class 20 30 50
Total 40 40 80
  1. If the two likes are independent, find the expected count for "likes reading, dislikes Japanese class" and for "likes reading, likes Japanese class". 2. Test H0 "no relationship" with Pearson's χ²: compute X² and decide at 5%. The 95th percentiles for 1, 2, 4 degrees of freedom are 3.84, 5.99, 9.49. 3. Using this test, explain Type I and Type II errors.

Solution.

  1. 30 · 40/80 = 15, and 50 · 40/80 = 25. (The other two expected counts are 15 and 25.)
  2. X² = (20−15)²/15 + (10−15)²/15 + (20−25)²/25 + (30−25)²/25 = 1.667 + 1.667 + 1 + 1 = 5.33. Degrees of freedom (2−1)(2−1) = 1. 5.33 > 3.84, so reject H0 at 5%: liking reading and liking Japanese class are related.
  3. Type I error: rejecting H0 when it is true. Here, concluding the two are related when they are not. Its probability is the significance level, 5%. Type II error: not rejecting H0 when it is false. Here, missing a real relationship. Since we rejected H0, the only error we could have made is Type I.

Say it out loud. "Expected counts are row total times column total over the grand total. The statistic is 5.3 on one degree of freedom, above 3.84, so we reject independence, with a 5 percent risk that this is a false alarm."

Q6. Machine learning: logistic regression gradient

Question. Data {xn, tn}, tn ∈ {0, 1}, weights w. E = −Σ {tn ln yn + (1 − tn) ln(1 − yn)}, yn = σ(an) = 1/(1 + exp(−an)), an = wᵀxn.

  1. Show ∂E/∂yn = (yn − tn)/(yn(1 − yn)). 2. Derive ∂yn/∂an and write it in terms of yn. 3. Derive the gradient of E with respect to w. 4. Name one optimisation method to find w that minimises E.

Solution.

  1. ∂E/∂yn = −tn/yn + (1 − tn)/(1 − yn) = [−tn(1 − yn) + (1 − tn)yn]/(yn(1 − yn)) = (yn − tn)/(yn(1 − yn)).
  2. ∂y/∂a = e^(−a)/(1 + e^(−a))² = y(1 − y).
  3. Chain rule: ∇_w E = Σ (∂E/∂yn)(∂yn/∂an) xn = Σ (yn − tn) xn.
  4. Gradient descent (or stochastic gradient descent, or Newton-Raphson, also called IRLS).

Say it out loud. "The sigmoid's derivative y(1 − y) cancels the denominator from the cross-entropy, so the gradient is just prediction minus target, times the input."

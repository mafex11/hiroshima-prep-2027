This is our own English version of the Informatics and Data Science Program's question set from 24 August 2023 (for October 2023 and April 2024 entry), with a worked answer after every question. Part I has four maths questions (linear algebra, calculus, probability, graph theory), and Part II has six subject questions (information theory, algorithms, C programming, digital circuits, linear regression, neural networks) and one short writing task.

Every number below was recomputed in Python, and the C program in Part II, Question 3 was compiled and run with the blanks filled in.

Part I: Informatics and Data Science I

Question 1

Let A = [aᵢⱼ] be an n × n real symmetric matrix. Let its n eigenvalues be λ₁ ≤ λ₂ ≤ ... ≤ λₙ, with corresponding eigenvectors u₁, u₂, ..., uₙ. Answer the following.

(1) Show that tr(A) = Σᵢ₌₁ⁿ λᵢ.

(2) Show that Σᵢ₌₁ⁿ Σⱼ₌₁ⁿ aᵢⱼ² = Σᵢ₌₁ⁿ λᵢ².

Answer.

A is real and symmetric, so by the spectral theorem we can choose the eigenvectors u₁, ..., uₙ to be orthonormal. Put them as the columns of U = [u₁ u₂ ... uₙ] and let Λ = diag(λ₁, ..., λₙ). Then UᵀU = UUᵀ = I and AU = UΛ, so

A = U Λ Uᵀ.

(1) Use tr(XY) = tr(YX):

tr(A) = tr(U Λ Uᵀ) = tr(Λ UᵀU) = tr(Λ) = λ₁ + λ₂ + ... + λₙ.

(Another route that works for any square matrix: det(λI − A) = (λ − λ₁)(λ − λ₂)...(λ − λₙ). The coefficient of λⁿ⁻¹ is −tr(A) on the left and −(λ₁ + ... + λₙ) on the right.)

(2) Because A is symmetric, aⱼᵢ = aᵢⱼ. So the (i, i) entry of A² is Σⱼ aᵢⱼ aⱼᵢ = Σⱼ aᵢⱼ², and

Σᵢ Σⱼ aᵢⱼ² = Σᵢ (A²)ᵢᵢ = tr(A²).

Now A² = U Λ Uᵀ U Λ Uᵀ = U Λ² Uᵀ, and A² has eigenvalues λ₁², ..., λₙ². By the same step as in (1),

tr(A²) = tr(Λ²) = λ₁² + λ₂² + ... + λₙ².

Python check on a random 5 × 5 symmetric matrix: both identities hold.

In one or two sentences: A symmetric matrix is a diagonal matrix of its eigenvalues seen in a rotated basis, and a rotation does not change the trace or the sum of squared entries. So both can be read straight off the eigenvalues.

Question 2

Let φ(u, v) and ψ(u, v) be functions of two variables of class C^∞ with φ(0, 0) = ψ(0, 0) = 0, and let f(x, y) = e^(−x² − y²) xy. Answer the following.

(1) Determine whether the function f(x, y) has a local extremum at (x, y) = (0, 0).

(2) Let ∂φ/∂u(0, 0) = a, ∂φ/∂v(0, 0) = b, ∂ψ/∂u(0, 0) = c and ∂ψ/∂v(0, 0) = d. Let g(u, v) = f(φ(u, v), ψ(u, v)) be the composite of f with φ and ψ. Find the Maclaurin expansion of g(u, v) up to the terms of degree 2 (the Maclaurin polynomial of degree 2).

(3) Assume ad − bc ≠ 0. Determine whether g(u, v) has a local extremum at (u, v) = (0, 0).

Answer.

(1) No, f has no local extremum at (0, 0). It is a saddle point.

The first derivatives are

f_x = e^(−x² − y²) y (1 − 2x²), f_y = e^(−x² − y²) x (1 − 2y²),

and both are 0 at (0, 0), so (0, 0) is a stationary point with f(0, 0) = 0. The second derivatives at (0, 0) are f_xx = 0, f_yy = 0, f_xy = 1, so the Hessian determinant is 0 · 0 − 1² = −1 < 0. That means a saddle point.

A direct view: e^(−x² − y²) > 0, so f has the same sign as xy. Arbitrarily close to the origin, f(t, t) = t² e^(−2t²) > 0 and f(t, −t) = −t² e^(−2t²) < 0, while f(0, 0) = 0. So (0, 0) is neither a local maximum nor a local minimum.

(2) Near the origin, e^(−x² − y²) = 1 − (x² + y²) + ..., so

f(x, y) = xy − xy(x² + y²) + ... = xy + (terms of degree 4 and higher).

Because φ(0, 0) = ψ(0, 0) = 0,

φ(u, v) = au + bv + (terms of degree 2 and higher), ψ(u, v) = cu + dv + (terms of degree 2 and higher).

φ and ψ have no constant term, so the degree-4 terms of f give terms of degree at least 4 in (u, v). So g = φψ + (degree ≥ 4) = (au + bv)(cu + dv) + (degree ≥ 3), and the Maclaurin polynomial of degree 2 is

g(u, v) ≈ ac u² + (ad + bc) uv + bd v².

The constant term and the linear terms are 0. (Chain-rule check: g_u(0, 0) = f_x φ_u + f_y ψ_u = 0 because f_x = f_y = 0 at the origin, and g_uu(0, 0) = 2 f_xy φ_u ψ_u = 2ac, g_uv(0, 0) = f_xy(φ_u ψ_v + φ_v ψ_u) = ad + bc, g_vv(0, 0) = 2bd.)

Python (sympy) check with general second-order terms in φ and ψ: the degree-2 part is exactly ac u² + (ad + bc) uv + bd v².

(3) No, g has no local extremum at (0, 0). It is a saddle point.

From (2), g(0, 0) = 0, the gradient of g at the origin is 0, and the Hessian matrix is

H = [ 2ac      ad + bc ]
    [ ad + bc  2bd     ]

with det H = 4abcd − (ad + bc)² = −(ad − bc)². Since ad − bc ≠ 0, det H < 0, so the origin is a saddle point. Python (sympy) gives det H = −(ad − bc)².

A plain picture: put s = au + bv and t = cu + dv. Since ad − bc ≠ 0, this change of variables is invertible, so small (s, t) can take any direction. Then g = st + (degree ≥ 3). Taking s = t = ε gives g ≈ ε² > 0, and s = −t = ε gives g ≈ −ε² < 0, for small ε. So g takes both signs next to the origin.

In one or two sentences: Near the origin f looks like xy, which is a saddle: positive in two quadrants and negative in the other two. When ad − bc ≠ 0 the change of variables (u, v) → (φ, ψ) is invertible near the origin, so g keeps the saddle shape and has no extremum there.

Question 3

Let X₁, X₂, ..., Xₙ be mutually independent and identically distributed discrete random variables. The probability mass function of Xᵢ (i = 1, 2, ..., n) is

P(Xᵢ = k) = pₖ, k = 0, 1, ..., m,

where pₖ ≥ 0 and Σₖ₌₀ᵐ pₖ = 1. Let the random variable Yₖ be the number of the Xᵢ among X₁, ..., Xₙ that are equal to k.

(1) When m = 1, prove that the probability P(Y₁ = k) is given by

P(Y₁ = k) = C(n, k) p₁ᵏ p₀ⁿ⁻ᵏ,

where C(n, k) = n! / (k! (n − k)!) is the binomial coefficient.

(2) When m = 1, find the mean E[Y₁] and the variance Var[Y₁].

(3) When m = 2, find the probability P(Y₁ = k).

(4) When m = 2, find the probability P(Y₂ = k | Y₁ = l).

(5) When m = 2, find the probability P(Y₁ = y₁, Y₂ = y₂).

Answer.

(1) With m = 1, each Xᵢ equals 1 with probability p₁ and 0 with probability p₀ = 1 − p₁. The event Y₁ = k means that exactly k of the n variables equal 1. For one fixed set of k positions, independence gives the probability p₁ᵏ p₀ⁿ⁻ᵏ (k ones and n − k zeros). There are C(n, k) ways to choose the positions, and these events do not overlap. So

P(Y₁ = k) = C(n, k) p₁ᵏ p₀ⁿ⁻ᵏ, k = 0, 1, ..., n.

This is the binomial distribution B(n, p₁).

(2) Write Y₁ = I₁ + I₂ + ... + Iₙ, where Iᵢ = 1 if Xᵢ = 1 and Iᵢ = 0 otherwise. Then E[Iᵢ] = p₁ and Var[Iᵢ] = p₁ − p₁² = p₁p₀. The Iᵢ are independent, so

E[Y₁] = n p₁, Var[Y₁] = n p₁ p₀ = n p₁ (1 − p₁).

Python check (n = 5, p₁ = 0.65, by listing every outcome): mean 3.25 = n p₁ and variance 1.1375 = n p₁ p₀.

(3) With m = 2, each Xᵢ either equals 1 (probability p₁) or does not (probability p₀ + p₂ = 1 − p₁). The same argument as (1) gives

P(Y₁ = k) = C(n, k) p₁ᵏ (p₀ + p₂)ⁿ⁻ᵏ = C(n, k) p₁ᵏ (1 − p₁)ⁿ⁻ᵏ, k = 0, 1, ..., n.

(4) Given Y₁ = l, the other n − l variables are each 0 or 2, still independently. For one of them, P(Xᵢ = 2 | Xᵢ ≠ 1) = p₂ / (p₀ + p₂) and P(Xᵢ = 0 | Xᵢ ≠ 1) = p₀ / (p₀ + p₂). So Y₂ given Y₁ = l is binomial with n − l trials:

P(Y₂ = k | Y₁ = l) = C(n − l, k) (p₂ / (p₀ + p₂))ᵏ (p₀ / (p₀ + p₂))ⁿ⁻ˡ⁻ᵏ, k = 0, 1, ..., n − l,

and 0 for other k. (This assumes p₀ + p₂ > 0, so that the condition can happen with l < n.)

(5) Multiply (3) and (4) with l = y₁ and k = y₂. The factors (p₀ + p₂)ⁿ⁻ʸ¹ cancel:

P(Y₁ = y₁, Y₂ = y₂) = C(n, y₁) C(n − y₁, y₂) p₁^y₁ p₂^y₂ p₀^(n − y₁ − y₂)

which simplifies to

P(Y₁ = y₁, Y₂ = y₂) = n! / (y₁! y₂! (n − y₁ − y₂)!) · p₀^(n − y₁ − y₂) p₁^y₁ p₂^y₂,

for integers y₁, y₂ ≥ 0 with y₁ + y₂ ≤ n, and 0 otherwise. This is the multinomial distribution (with Y₀ = n − y₁ − y₂ zeros).

Python check: listing all 3⁵ outcomes for n = 5 and (p₀, p₁, p₂) = (0.2, 0.5, 0.3), the formulas in (3), (4) and (5) all match.

In one or two sentences: Counting how many of n independent draws land on one value gives a binomial distribution, and counting two values at once gives a multinomial one. Once you know how many draws are 1, the rest are 0 or 2, so the count of 2s is binomial again with the probabilities rescaled.

Question 4

A graph drawn in the plane, made of a set of vertices and a set of edges that join the vertices without any crossing, is called a plane graph. A graph is called planar if it is isomorphic to a plane graph. Let Kₓ denote the complete graph of order x (order = number of vertices). Answer the following.

(1) Is K₄ planar? Answer with the reason.

(2) A graph with no self-loops and at most one edge between any two vertices is called a simple graph. A simple planar graph that stops being planar when an edge is added between any two vertices (not already joined) is called a maximal planar graph. Prove that the number of edges q of a maximal planar graph of order p (≥ 3) satisfies q = (3/2)r, where r is the number of regions (faces) of its plane drawing.

(3) Using the above result, prove that the number of edges q of any planar graph of order p satisfies q ≤ 3p − 6. In the proof you may use Euler's formula for plane graphs.

(4) K₅ has 10 edges, so the above result shows that K₅ is not planar. Is the graph obtained by deleting any one edge from K₅ planar? Answer with the reason. Note that "q ≤ 3p − 6" is a necessary condition for a graph to be planar, but not a sufficient one.

Answer.

(1) Yes, K₄ is planar. Draw a triangle on vertices 1, 2, 3 and put vertex 4 inside it, joined to 1, 2 and 3:

            1
           /|\
          / | \
         /  4  \
        / /   \ \
       //       \\
      2-----------3

All six edges 12, 13, 23, 14, 24, 34 are drawn with no crossing. (Euler check: p = 4, q = 6, r = 4 faces, three small triangles plus the outer face, and 4 − 6 + 4 = 2.)

(2) Let G be a maximal planar graph of order p ≥ 3, drawn in the plane with no crossings.

  • G is connected. Otherwise two of its components border a common face, and an edge between them could be drawn inside that face without a crossing, which contradicts maximality.
  • Every face is bounded by exactly 3 edges (a triangle). Suppose a face F has 4 or more vertices on its boundary, and let v₁, v₂, v₃, v₄ be consecutive boundary vertices. If v₁ and v₃ are not joined, the edge v₁v₃ can be drawn inside F, which contradicts maximality. If v₁v₃ is already an edge, it runs outside F. Then v₂ and v₄ cannot be joined, because an edge v₂v₄ outside F would have to cross v₁v₃ (the four vertices alternate around F). So v₂v₄ can be drawn inside F, again a contradiction. A face also cannot have fewer than 3 boundary edges, because G is simple and has at least 3 vertices.
  • Count pairs (edge, face) where the edge lies on the boundary of the face. Each face has 3 boundary edges, so the count is 3r. Each edge separates exactly two faces, one on each side, so the count is also 2q.

So 2q = 3r, that is, q = (3/2)r.

(3) Let G be a planar graph of order p ≥ 3 with q edges. G is simple, as defined in (2); with repeated edges the bound would fail. Keep adding edges (keeping the graph simple and planar) until no edge can be added. The result G′ is a maximal planar graph of order p with q′ ≥ q edges and r′ faces. G′ is connected, so Euler's formula gives

p − q′ + r′ = 2.

By (2), r′ = (2/3)q′. Then p − q′ + (2/3)q′ = 2, so q′ = 3p − 6. Hence

q ≤ q′ = 3p − 6.

(The bound needs p ≥ 3, as in (2). For p = 2, K₂ has 1 edge but 3p − 6 = 0.)

(4) Yes, K₅ minus any one edge is planar. K₅ is symmetric (every edge looks the same), so deleting any edge gives the same graph up to isomorphism. Call the ends of the deleted edge 4 and 5. Take the K₄ drawing from (1) on vertices 1, 2, 3, 4, and put vertex 5 outside the triangle, joined to 1, 2 and 3. A straight-line drawing with no crossings uses these coordinates:

  • 1 = (0, 2), 2 = (−2, 0), 3 = (2, 0), 4 = (0, 0.7) inside the triangle, 5 = (0, 4) above vertex 1.
  • Edges: 12, 13, 23, 14, 24, 34, 15, 25, 35 (9 edges; only 45 is missing).

Vertex 5 sits above 1, so its edges to 2 and 3 pass outside the triangle 1-2-3, and its edge to 1 is a short vertical segment. Python check: no two of these 9 segments cross. The drawing has 6 faces: 1-2-4, 1-3-4, 2-3-4, 5-1-2, 5-1-3 and the outer face 5-2-3, all triangles. This fits (2) and (3): q = 9 = (3/2) · 6 and q = 3p − 6 = 9, so the graph is in fact maximal planar.

The reason we need a drawing: 9 ≤ 3 · 5 − 6 = 9 holds, but that inequality alone does not prove planarity, since it is only a necessary condition. The explicit drawing proves it.

In one or two sentences: In a maximal planar drawing every face is a triangle, so 2q = 3r, and Euler's formula then gives at most 3p − 6 edges. K₅ has one edge too many, but K₅ minus any edge can be drawn as a triangle with one vertex inside and one outside, so it is planar.

Part II: Informatics and Data Science II

Question 1

As shown in Table 1, let 𝒜 be a binary code for the information source S = {s₁, s₂, s₃, s₄}.

Table 1: Information source S and the corresponding binary code 𝒜

S 𝒜
s₁ 0
s₂ 110
s₃ 10
s₄ x

(1) Find one 4-digit codeword x that makes 𝒜 instantaneously decodable.

(2) Draw the binary tree of the code 𝒜 from (1), and use it to explain why 𝒜 is instantaneously decodable.

(3) Write out 𝒜², the second-order extension of 𝒜 from (1).

(4) Explain whether 𝒜 is uniquely decodable or not.

Answer.

(1) x = 1110 (x = 1111 also works).

A code is instantaneously decodable exactly when it is prefix-free: no codeword is the start of another codeword. So x must not start with 0 (the codeword of s₁), with 10 (s₃) or with 110 (s₂). That leaves only 4-digit words that start with 111, which are 1110 and 1111. Python check over all 16 four-bit words: only 1110 and 1111 give a prefix-free code. Below we use x = 1110.

(2) Binary tree (0 = left branch, 1 = right branch):

          (root)
         0/    \1
        s1     ( )
              0/  \1
             s3   ( )
                 0/  \1
                s2   ( )
                    0/  \1
                   s4  (unused)

Every codeword ends at a leaf, and no codeword sits on the path to another one. The decoder walks down the tree bit by bit. When it reaches a leaf it outputs that symbol at once and goes back to the root, without needing to look at any later bit. That is what "instantaneously decodable" means. (The branch 1111 is unused.)

(3) 𝒜² gives each pair of symbols sᵢsⱼ the codeword of sᵢ followed by the codeword of sⱼ. With x = 1110 (row = first symbol, column = second symbol):

s₁ s₂ s₃ s₄
s₁ 00 0110 010 01110
s₂ 1100 110110 11010 1101110
s₃ 100 10110 1010 101110
s₄ 11100 1110110 111010 11101110

For example s₂s₃ ↦ 110 10 = 11010. (The 16 pairs, recomputed in Python.)

(4) Yes, 𝒜 is uniquely decodable. Every instantaneous (prefix-free) code is uniquely decodable. Read the bits from the left: as soon as the bits read so far form a codeword, it must be the next symbol, because no other codeword starts with it. So any bit string splits into codewords in only one way. This is consistent with the Kraft–McMillan inequality: 2⁻¹ + 2⁻³ + 2⁻² + 2⁻⁴ = 15/16 ≤ 1. Python also ran the Sardinas–Patterson check on {0, 110, 10, 1110}: uniquely decodable.

(A bad choice of x would break this. For example, with x = 0110 the string 0110 could be s₄ or s₁s₂, so that code would not be uniquely decodable.)

In one or two sentences: Choosing x = 1110 makes the code prefix-free, so every codeword is a leaf of the code tree and each symbol can be decoded the moment its last bit arrives. A prefix-free code is always uniquely decodable.

Question 2

Let A[1..n] be an array of n distinct numbers. If i < j and A[i] > A[j], the pair (i, j) is called an inversion of A. Answer the following.

(1) List all inversions of the array A₁ = ⟨2, 1, 4, 3⟩.

(2) Find the number of inversions of the array A₂ = ⟨3, 2, 8, 6, 1⟩.

(3) Among all arrays that contain all n elements of the set {1, 2, ..., n}, give the array A₃ with the most inversions. Also find the number of inversions of this array A₃.

(4) Consider running the pseudocode Insertion-Sort(A₂). Give all the values of the variables i and j and of the array A₂ just after line 5 and line 7 of the pseudocode are executed, in order of execution. A₂ is the array from (2).

(5) Describe the relationship between the running time of the pseudocode Insertion-Sort(A) and the number of inversions in the input array A.

(6) If you can design an algorithm that finds the number of inversions of any permutation of n elements in Θ(n log n) time in the worst case, outline it. If you cannot, explain why.

Insertion-Sort(A)
1  for j = 2 to A.length
2      key = A[j]
3      i = j - 1
4      while i > 0 and A[i] > key
5          A[i + 1] = A[i]
6          i = i - 1
7      A[i + 1] = key

Answer.

(1) (1, 2) and (3, 4), as index pairs. The values are 2 > 1 and 4 > 3. So A₁ has 2 inversions.

(2) 6 inversions. As index pairs: (1, 2) for 3 > 2, (1, 5) for 3 > 1, (2, 5) for 2 > 1, (3, 4) for 8 > 6, (3, 5) for 8 > 1, (4, 5) for 6 > 1. Python gives the same 6 pairs.

(3) A₃ = ⟨n, n − 1, ..., 2, 1⟩, the descending order. Every pair i < j is an inversion, so A₃ has C(n, 2) = n(n − 1)/2 inversions. No array can have more, because there are only C(n, 2) pairs. Python check by trying every permutation for n = 1 to 6: the maximum is 0, 1, 3, 6, 10, 15, always reached by the descending array.

(4) Line 6 lowers i, so just after line 5 the variable i still has its value from line 4. The trace:

Step Just after j i A₂
1 line 5 2 1 ⟨3, 3, 8, 6, 1⟩
2 line 7 2 0 ⟨2, 3, 8, 6, 1⟩
3 line 7 3 2 ⟨2, 3, 8, 6, 1⟩
4 line 5 4 3 ⟨2, 3, 8, 8, 1⟩
5 line 7 4 2 ⟨2, 3, 6, 8, 1⟩
6 line 5 5 4 ⟨2, 3, 6, 8, 8⟩
7 line 5 5 3 ⟨2, 3, 6, 6, 8⟩
8 line 5 5 2 ⟨2, 3, 3, 6, 8⟩
9 line 5 5 1 ⟨2, 2, 3, 6, 8⟩
10 line 7 5 0 ⟨1, 2, 3, 6, 8⟩

(For j = 3, key = 8 is already larger than A[2] = 3, so line 5 does not run.) Line 5 runs 6 times, which equals the number of inversions from (2). Python reproduces this table.

(5) Each run of line 5 moves one larger element one step to the right past key, and this removes exactly one inversion. Sorting ends with 0 inversions, so line 5 runs exactly I times in total, where I is the number of inversions of the input. Lines 2, 3 and 7 run n − 1 times (the loop test in line 1 runs n times). So the running time is Θ(n + I):

  • already sorted input (I = 0): Θ(n), the best case;
  • reversed input (I = n(n − 1)/2): Θ(n²), the worst case;
  • a random permutation has n(n − 1)/4 inversions on average, so Θ(n²) on average.

(6) Yes, it can be done. Count the inversions while doing merge sort:

  1. Split the array into a left half and a right half. Recursively sort each half and count the inversions inside it.
  2. Merge the two sorted halves. Whenever the next element taken comes from the right half while elements are still left in the left half, each of those remaining left elements is larger than it and comes before it. So add the number of elements still left in the left half.
  3. The total is (inversions in the left half) + (inversions in the right half) + (inversions counted during the merge).

The merge takes Θ(n), so T(n) = 2T(n/2) + Θ(n) = Θ(n log n) for every input, including the worst case. Python check: this merge-based count matched a brute-force count on 300 random permutations of 9 elements, and gives 6 for A₂.

In one or two sentences: An inversion is a pair that is out of order, and insertion sort does exactly one shift per inversion, so its running time is Θ(n + number of inversions). Merge sort can count all inversions while it merges, in Θ(n log n).

Question 3

Listing 1 is an example implementation of a stack in the C language, together with a program that uses it to check whether the brackets in a text are balanced ("{" is closed by "}", and "[" is closed by "]"). Here β ∈ ℝᵖ is the vector of regression coefficients, xᵢ ∈ ℝᵖ is the vector of explanatory variables, and ε := (ε₁, ..., εₙ)ᵀ is a random vector drawn from the multivariate normal distribution with mean 0 ∈ ℝⁿ and covariance matrix Σ ∈ ℝⁿˣⁿ, that is, ε ~ N(0, Σ). For the observed data (yᵢ, xᵢ) (i = 1, ..., n), define β̂ := (XᵀX)⁻¹Xᵀy, where

X := (x₁ᵀ; x₂ᵀ; ...; xₙᵀ) ∈ ℝⁿˣᵖ (the n × p matrix whose i-th row is xᵢᵀ), and y := (y₁, y₂, ..., yₙ)ᵀ ∈ ℝⁿ.

Assume rank(X) = p.

(1) Let ŷ := Xβ̂. Show that E[ŷ] = E[y].

(2) Find Var[ŷ], the covariance matrix of ŷ.

Answer.

Treat X as fixed (not random). The data vector is y = Xβ + ε. Since rank(X) = p, the p × p matrix XᵀX is invertible. Let

H := X(XᵀX)⁻¹Xᵀ (the "hat" matrix), so ŷ = Xβ̂ = Hy.

H is symmetric (Hᵀ = H), idempotent (H² = H), and HX = X(XᵀX)⁻¹XᵀX = X.

(1) E[y] = Xβ + E[ε] = Xβ. So

E[ŷ] = H E[y] = HXβ = Xβ = E[y].

(2) For a fixed matrix H, Var[Hy] = H Var[y] Hᵀ, and Var[y] = Var[ε] = Σ. So

Var[ŷ] = HΣHᵀ = HΣH = X(XᵀX)⁻¹Xᵀ Σ X(XᵀX)⁻¹Xᵀ.

In the common special case Σ = σ²I (independent errors with equal variance), this becomes Var[ŷ] = σ²H² = σ²H = σ²X(XᵀX)⁻¹Xᵀ.

Question 6

The softmax function is often used in artificial neural networks. It takes a vector of real numbers z = (z₁, z₂, ..., z_K) as input and outputs a probability distribution, the vector p = (p₁, p₂, ..., p_K). Here K is the dimension of the vector. The softmax function is defined as

σ(z) = ( exp(z₁) / Σₖ₌₁ᴷ exp(zₖ), exp(z₂) / Σₖ₌₁ᴷ exp(zₖ), ..., exp(z_K) / Σₖ₌₁ᴷ exp(zₖ) ).

Answer all of the following.

(1) For a K-dimensional vector c = (c, c, ..., c), where c is any real number, prove that

σ(z + c) = σ(z).

(2) Let H > 0 be a real number. Describe how σ(z/H) behaves when H is sufficiently large and when H is sufficiently small.

(3) Derive the derivative of σ(z) with respect to zᵢ (1 ≤ i ≤ K).

Answer.

Write S = Σₖ₌₁ᴷ exp(zₖ) and σⱼ = exp(zⱼ)/S for the j-th output.

(1) The j-th component of σ(z + c) is

exp(zⱼ + c) / Σₖ exp(zₖ + c) = eᶜ exp(zⱼ) / (eᶜ Σₖ exp(zₖ)) = exp(zⱼ) / Σₖ exp(zₖ) = σⱼ(z).

This holds for every j, so σ(z + c) = σ(z). (This is why programs subtract the largest zₖ before taking exp: the result is the same and exp cannot overflow.)

(2) H acts like a temperature.

  • H sufficiently large: z/H → 0, so every exp(zⱼ/H) → 1 and σ(z/H) → (1/K, 1/K, ..., 1/K). The output becomes flat (uniform) and the differences between the zⱼ stop mattering.
  • H sufficiently small (H → +0): let z_max be the largest component. By (1), σ(z/H) = σ((z − z_max)/H). For each zⱼ < z_max, (zⱼ − z_max)/H → −∞, so its exp → 0. So σ(z/H) tends to the one-hot vector with 1 at the position of the largest component (if m components tie for the largest, each of them gets 1/m). The function then works like argmax, a "hard" maximum.

Python check with z = (1, 3, −0.5, 2): H = 1000 gives about (0.2499, 0.2504, 0.2495, 0.2502), and H = 0.01 gives about (1.4 × 10⁻⁸⁷, 1, 9.9 × 10⁻¹⁵³, 3.7 × 10⁻⁴⁴).

(3) By the quotient rule, using ∂exp(zⱼ)/∂zᵢ = δᵢⱼ exp(zⱼ) and ∂S/∂zᵢ = exp(zᵢ):

∂σⱼ/∂zᵢ = (δᵢⱼ exp(zⱼ) S − exp(zⱼ) exp(zᵢ)) / S² = σⱼ(δᵢⱼ − σᵢ),

where δᵢⱼ = 1 if i = j and 0 otherwise. So

  • ∂σᵢ/∂zᵢ = σᵢ(1 − σᵢ),
  • ∂σⱼ/∂zᵢ = −σᵢσⱼ for j ≠ i.

As a vector, ∂σ(z)/∂zᵢ = σᵢ(z) (eᵢ − σ(z)), where eᵢ is the i-th unit vector. The full Jacobian matrix is diag(σ) − σσᵀ. Python check: this matches a finite-difference Jacobian at z = (1, 3, −0.5, 2).

In one or two sentences: Softmax only cares about the differences between its inputs, so adding the same number to all of them changes nothing. Dividing by a large H flattens it toward uniform, a small H sharpens it toward a one-hot argmax, and its derivative is σⱼ(δᵢⱼ − σᵢ).

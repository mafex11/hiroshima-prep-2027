August 2024: questions and answers

When and how long: If time.

This is our own English version of the Informatics and Data Science Program's question set from 22 August 2024, for students starting in October 2024 or April 2025. Part I (four questions) is maths: a matrix built from rotations, a maximum and an improper double integral, the Poisson distribution, and colouring planar graphs; Part II (seven questions) covers information theory, counting sort, two C programs (a linked list and an array), circuits made of NOR gates, the normal distribution, machine learning terms, and a short write-up of your own research.

How this file was made: every question was translated from the Japanese and English original, and every figure is described in words. No model answer for this set is in these notes, so every answer below is our own. Every numeric result was recomputed in Python (sympy, mpmath, networkx) on 13 Nov 2026, the smallest NOR circuits were confirmed by a computer search over all smaller circuits, and both C programs were compiled and run. Anything I am not fully sure of is marked [CHECK] and listed at the end.

Notation: ᵀ is a transpose, log is the natural logarithm (base e) unless written log₂, ¬ means NOT, ∨ means OR and ∧ means AND.

Part I: Informatics and Data Science I

Question 1

Let

    [ cos θ   −sin θ ] [ 2  0 ] [  cos θ   sin θ ]
A = [ sin θ    cos θ ] [ 0  3 ] [ −sin θ   cos θ ]

where θ is a real number.

(1) Find the determinant of A.

(2) Find the eigenvalues λ₁, λ₂ of A and corresponding eigenvectors v₁, v₂ of length 1.

(3) Show that xᵀAx > 0 holds for every nonzero vector x ∈ ℝ², where xᵀ is the transpose of x.

(4) Let θ = π/4. For a positive integer n, find Aⁿ.

Answer.

Call the first matrix R and the middle one D = diag(2, 3). The third matrix is Rᵀ, the transpose of R. R is a rotation by θ, so RᵀR = RRᵀ = I and det R = cos²θ + sin²θ = 1. So A = R D Rᵀ = R D R⁻¹. Multiplied out:

    [ 2cos²θ + 3sin²θ    −sin θ cos θ    ]   [ 2 + sin²θ       −sin θ cos θ ]
A = [ −sin θ cos θ       2sin²θ + 3cos²θ ] = [ −sin θ cos θ    2 + cos²θ    ]

A is symmetric.

(1) det A = det R × det D × det Rᵀ = 1 × 6 × 1 = 6. Check from the entries: (2 + sin²θ)(2 + cos²θ) − sin²θ cos²θ = 4 + 2(sin²θ + cos²θ) = 6.

(2) A = R D R⁻¹ is similar to D, so it has the same eigenvalues: λ₁ = 2, λ₂ = 3 (the characteristic polynomial is (λ − 2)(λ − 3)). For the eigenvectors, with e₁ = (1, 0)ᵀ and e₂ = (0, 1)ᵀ:

A(Re₁) = R D Rᵀ R e₁ = R D e₁ = 2Re₁, and in the same way A(Re₂) = 3Re₂.

So the eigenvectors are the columns of R:

v₁ = (cos θ, sin θ)ᵀ for λ₁ = 2, and v₂ = (−sin θ, cos θ)ᵀ for λ₂ = 3.

Both have length √(cos²θ + sin²θ) = 1. (−v₁ and −v₂ are also correct.)

(3) Let x ≠ 0 and put y = Rᵀx = (y₁, y₂)ᵀ. R is invertible, so y ≠ 0. Then

xᵀAx = xᵀ R D Rᵀ x = (Rᵀx)ᵀ D (Rᵀx) = yᵀDy = 2y₁² + 3y₂² > 0,

because both coefficients are positive and y₁, y₂ are not both 0. So A is positive definite. (In words: in the rotated coordinates the quadratic form has only positive squares.)

(4) Aⁿ = (R D Rᵀ)(R D Rᵀ)···(R D Rᵀ) = R Dⁿ Rᵀ, because each RᵀR in the middle is I. With θ = π/4, cos θ = sin θ = 1/√2 and Dⁿ = diag(2ⁿ, 3ⁿ), so

       [ (2ⁿ + 3ⁿ)/2    (2ⁿ − 3ⁿ)/2 ]
Aⁿ  =  [ (2ⁿ − 3ⁿ)/2    (2ⁿ + 3ⁿ)/2 ]

Check: n = 1 gives A = [[5/2, −1/2], [−1/2, 5/2]], and n = 2 gives [[13/2, −5/2], [−5/2, 13/2]] (confirmed in Python up to n = 6).

In one or two sentences: A is a rotation, times diag(2, 3), times the rotation back, so it has determinant 6, eigenvalues 2 and 3, and the rotated axes as eigenvectors. In the rotated coordinates xᵀAx is 2y₁² + 3y₂², which is positive, and taking powers only raises the 2 and the 3 to the n.

Follow-ups (each builds on your last answer)

  1. Prof: "You found Aⁿ. What does Aⁿ divided by 3ⁿ look like when n is large?"
    You: "Each entry is two thirds to the power n, plus or minus 1, all over 2, so the matrix tends to one half on the diagonal and minus one half off it. That limit is v₂ times v₂ transposed, the projection onto the eigenvector for 3, because the part along v₁ shrinks like two thirds to the power n."
  2. Prof: "So repeated multiplication picks out the largest eigenvalue. How would you use that on a big matrix, and how fast does it work?"
    You: "That's power iteration: I start from almost any vector, multiply by the matrix, rescale it to length 1, and repeat. The part along the other eigenvector shrinks each step by the ratio of the second largest eigenvalue to the largest, here two thirds, so after 20 steps it is about 0.0003 of the main part. It fails only if the starting vector has no component at all along the top eigenvector, and it is slow when the two largest eigenvalues are close."
  3. Prof: "Where does that idea show up in reliability work, for example in our lab's Markov models?"
    You: "In the steady state of a discrete-time Markov chain: pi equals pi times P, so the long-run distribution is the eigenvector of P for eigenvalue 1, and multiplying any starting distribution by P again and again converges to it. If a machine fails with probability 0.1 and is repaired with probability 0.4 in each step, the other eigenvalue is 1 minus 0.1 minus 0.4, which is 0.5, so the gap to the steady state halves every step. The long-run availability is 0.4 over 0.1 plus 0.4, which is 0.8."

Question 2

Consider the function

              { x log( 1 / (x² + y²) )    if (x, y) ≠ (0, 0)
z = f(x, y) = {
              { k                         if (x, y) = (0, 0)

defined on the region D = {(x, y) | 0 ≤ x, 0 ≤ y, 0 ≤ x² + y² ≤ 1} (the quarter of the unit disc in the first quadrant), where the function z = f(x, y) is continuous at the origin (0, 0).

(1) Find the value of k.

(2) Find the maximum value of z = f(x, y).

(3) Evaluate the following improper double integral.

∬_D f(x, y) dx dy

Answer. Use polar coordinates x = r cos φ, y = r sin φ with 0 < r ≤ 1 and 0 ≤ φ ≤ π/2. Then log(1/(x² + y²)) = −2 log r, so on D without the origin

f = −2 r cos φ log r.

(1) |f| ≤ 2r |log r|, and r log r → 0 as r → 0+. So f(x, y) → 0 as (x, y) → (0, 0), and continuity at the origin needs k = 0.

(2) For 0 < r ≤ 1 we have log r ≤ 0, so f ≥ 0 everywhere on D. For a fixed r, f is largest when cos φ = 1, that is on the edge y = 0. There

f(x, 0) = −2x log x = g(x), g′(x) = −2 log x − 2,

and g′(x) = 0 at x = 1/e. g′ > 0 for x < 1/e and g′ < 0 for x > 1/e, so this is the maximum: g(1/e) = −2(1/e)(−1) = 2/e. On the other two edges f = 0 (on x = 0, and on the arc r = 1, where log 1 = 0).

Maximum value: 2/e ≈ 0.7358, reached at (x, y) = (1/e, 0).

The partial derivatives give the same picture: ∂f/∂y = −2xy/(x² + y²) is negative wherever x > 0 and y > 0, so there is no stationary point strictly inside D, f falls as y grows, and the maximum is on the edge y = 0. A grid search in Python found the same maximum.

(3) The log factor is unbounded near the origin, so the integral is the limit over D with a small quarter disc of radius ε removed, as ε → 0+. In polar coordinates (dx dy = r dr dφ) the integral splits into two factors:

∬D f dx dy = lim(ε→0+) ( ∫₀^(π/2) cos φ dφ ) × ( ∫_ε^1 −2 r² log r dr ) = 1 × (−2) × ∫₀¹ r² log r dr.

By parts, ∫ r² log r dr = (r³/3) log r − r³/9. On [ε, 1] this gives −1/9 − ((ε³/3) log ε − ε³/9), which tends to −1/9 as ε → 0+ (because ε³ log ε → 0). So

∬_D f(x, y) dx dy = −2 × (−1/9) = 2/9 ≈ 0.2222.

(Python: exactly 2/9 in sympy, and 0.222222... by numerical integration in both polar and x-y coordinates.)

In one or two sentences: Near the origin x log(1/r²) behaves like r log r, which goes to 0, so k = 0. The function is largest on the x-axis at x = 1/e, with value 2/e, and in polar coordinates the integral splits into ∫cos φ dφ = 1 times −2∫r² log r dr = 2/9.

Follow-ups (each builds on your last answer)

  1. Prof: "You used the fact that r log r goes to 0 as r goes to 0. How do you prove that?"
    You: "I write r log r as log r divided by 1 over r, where both blow up, and use L'Hôpital's rule: the ratio of the derivatives is 1 over r divided by minus 1 over r squared, which is minus r, and that goes to 0. Put simply, log r blows up more slowly than any power of 1 over r."
  2. Prof: "Then for which powers a does the integral of r to the a times log r, from 0 to 1, converge, and what is its value?"
    You: "For every a greater than minus 1, and the value is minus 1 over, a plus 1, squared. The quick way: the integral of r to the a is 1 over a plus 1, and differentiating r to the a with respect to a gives r to the a times log r, so I just differentiate 1 over a plus 1. With a equal to 2 that's minus one ninth, the integral I used in part (3). At a equal to minus 1 it diverges, because log r over r integrates to log r squared over 2, which blows up at 0."
  3. Prof: "Where does an integral of a power times a log show up in reliability modelling?"
    You: "In the power-law NHPP, the Crow-AMSAA model, where the expected number of failures by time t is alpha times t to the beta. Given n failures up to time T, each failure time divided by T acts like an independent draw with density beta times u to the beta minus 1, and this integral gives the mean of minus log u as 1 over beta. So n over the sum of the logs of T over each failure time estimates beta, and that is also its maximum likelihood estimate. A beta below 1 means the failures are thinning out, which is reliability growth."

Question 3

Let X₁, X₂ be independent random variables with the following probability mass functions:

P(Xᵢ = x) = e^(−μᵢ) μᵢˣ / x!, x = 0, 1, ..., i = 1, 2,

where μ₁, μ₂ are positive real numbers.

(1) Find the mean E[X₁] and the variance Var[X₁].

(2) Find the probability generating function E[z^(X₁)].

(3) Find P(X₁ + X₂ = x).

(4) Find P(X₁ = x | X₁ + X₂ = n), where n is a positive integer.

Answer. Each Xᵢ is a Poisson random variable with parameter μᵢ.

(1) E[X₁] = Σ_(x≥1) x e^(−μ₁) μ₁ˣ/x! = μ₁ e^(−μ₁) Σ_(x≥1) μ₁^(x−1)/(x−1)! = μ₁ e^(−μ₁) e^(μ₁) = μ₁.

In the same way, E[X₁(X₁ − 1)] = μ₁² e^(−μ₁) Σ_(x≥2) μ₁^(x−2)/(x−2)! = μ₁². So E[X₁²] = μ₁² + μ₁, and

Var[X₁] = E[X₁²] − (E[X₁])² = μ₁² + μ₁ − μ₁² = μ₁.

(2) E[z^(X₁)] = Σ_(x≥0) e^(−μ₁) (μ₁z)ˣ/x! = e^(−μ₁) e^(μ₁z) = e^(μ₁(z − 1)).

Check: with G(z) = e^(μ₁(z − 1)), G′(1) = μ₁ = E[X₁] and G″(1) = μ₁² = E[X₁(X₁ − 1)], matching (1).

(3) For x = 0, 1, 2, ..., by independence and the binomial theorem:

P(X₁ + X₂ = x) = Σ_(j=0..x) P(X₁ = j) P(X₂ = x − j) = e^(−(μ₁+μ₂)) (1/x!) Σ_(j=0..x) C(x, j) μ₁ʲ μ₂^(x−j) = e^(−(μ₁+μ₂)) (μ₁ + μ₂)ˣ / x!

So X₁ + X₂ is Poisson with parameter μ₁ + μ₂. Quick check with (2): E[z^(X₁+X₂)] = e^(μ₁(z−1)) e^(μ₂(z−1)) = e^((μ₁+μ₂)(z−1)), which is the generating function of a Poisson variable with parameter μ₁ + μ₂.

(4) The event {X₁ = x, X₁ + X₂ = n} is the same as {X₁ = x, X₂ = n − x}. So for x = 0, 1, ..., n:

P(X₁ = x | X₁ + X₂ = n) = P(X₁ = x) P(X₂ = n − x) / P(X₁ + X₂ = n) = [e^(−μ₁) μ₁ˣ / x!] [e^(−μ₂) μ₂^(n−x) / (n − x)!] / [e^(−(μ₁+μ₂)) (μ₁ + μ₂)ⁿ / n!] = C(n, x) (μ₁/(μ₁ + μ₂))ˣ (μ₂/(μ₁ + μ₂))^(n−x),

and 0 for x > n. This is the binomial distribution with n trials and success probability μ₁/(μ₁ + μ₂). (Both (3) and (4) were checked numerically in Python with μ₁ = 1.7, μ₂ = 2.6, n = 6.)

In one or two sentences: A Poisson variable has mean and variance both equal to μ and generating function e^(μ(z − 1)). The sum of two independent Poisson variables is Poisson with the summed parameter, and given the total n, X₁ is binomial with n trials and probability μ₁/(μ₁ + μ₂).

Follow-ups (each builds on your last answer)

  1. Prof: "You showed the mean and the variance are both μ. How would you use that to check whether real data, say faults found per week, is Poisson?"
    You: "I'd compare the sample variance with the sample mean: their ratio, the dispersion index, should be close to 1. If the data are Poisson, the sum of squared deviations divided by the mean is roughly chi-square with n minus 1 degrees of freedom, so I can test it. If the variance is clearly larger, the data are overdispersed, and a plain Poisson model understates the spread."
  2. Prof: "Where would that overdispersion come from, and what model would you use instead?"
    You: "Usually from a rate that isn't constant, for example some weeks or some modules are buggier than others. If the Poisson rate itself follows a gamma distribution, the count is negative binomial, and by the law of total variance its variance is the mean plus the mean squared over the gamma shape. With mean 4 and shape 2, that's 12, three times the mean."
  3. Prof: "Your plan does something similar with failing runs. What is the variance there?"
    You: "Yes, it's the same idea with a binomial. The chance that a run fails changes from input to input, and if it follows a beta distribution, the number of failing runs out of k is beta-binomial, with variance k p times 1 minus p, times 1 plus k minus 1 times rho, where rho is the intraclass correlation. With 10 runs and a rho of, say, 0.1, that's 1.9 times the binomial variance, and that extra spread is what I fit to measure how much runs fail together."

Question 4

A graph is called planar if it can be drawn in the plane with no two edges crossing. Giving each vertex of a graph a colour so that adjacent vertices never get the same colour is called a vertex colouring of the graph.

(1) Give an example of a planar graph of order six (six vertices) that cannot be vertex-coloured with three or fewer colours. In your answer, show that the graph really is planar and explain why it cannot be vertex-coloured with three or fewer colours.

(2) It is known that a simple planar graph of order n has at most 3n − 6 edges. Using this fact, prove that every simple planar graph has at least one vertex of degree five or less.

(3) Let Statement A be "any planar graph of order n can be vertex-coloured with five or fewer colours". Prove that Statement A holds for every natural number n less than or equal to four.

(4) Let n be a natural number greater than or equal to four, and assume that Statement A holds for n. Prove that if a planar graph G of order n + 1 has a vertex of degree four or less, then G can be vertex-coloured with five or fewer colours.

Answer.

(1) Take the wheel with six vertices: a cycle of five vertices 1-2-3-4-5-1 (the rim) and a sixth vertex h (the hub) joined to all five. It has 6 vertices and 10 edges: the rim edges 1-2, 2-3, 3-4, 4-5, 5-1 and the spokes h-1, h-2, h-3, h-4, h-5.

It is planar: draw the rim as a regular pentagon and put h in the centre. The five spokes run straight from the centre to the corners, so they stay inside the pentagon and meet only at h. No two edges cross.

              1
            / | \
          /   |   \
        5 --- h --- 2
         \   / \   /
          \ /   \ /
           4 --- 3

It cannot be coloured with three or fewer colours. The rim is a cycle of odd length 5. With two colours, the colours would have to alternate around the cycle, which is impossible for an odd cycle, so the rim alone already uses all three colours. The hub is adjacent to all five rim vertices, so it cannot take any of those three colours, and a fourth colour is needed. (Four colours are enough: rim 1, 2, 1, 2, 3 in order and hub 4.) A computer check of all 3⁶ = 729 ways to colour it with three colours found none that works.

Another correct answer: K₄ (four vertices, every pair joined, drawn as a triangle with the fourth vertex inside) plus two more vertices joined to it by a path. K₄ needs four colours because its four vertices are pairwise adjacent.

(2) Proof by contradiction. Let G be a simple planar graph with n vertices and m edges, and suppose every vertex has degree at least 6. The sum of the degrees counts every edge twice, so

2m = Σ deg(v) ≥ 6n, so m ≥ 3n.

But the known fact says m ≤ 3n − 6 < 3n. This is a contradiction, so some vertex has degree at most 5.

(Small graphs: the bound 3n − 6 is meant for n ≥ 3. If n ≤ 6, every vertex of a simple graph has degree at most n − 1 ≤ 5 anyway, so the claim holds there without the bound.)

(3) If n ≤ 4, give every vertex a different colour. That uses n ≤ 4 ≤ 5 colours, and adjacent vertices always get different colours, because no two vertices share a colour. So Statement A holds for n = 1, 2, 3, 4. (As usual for colouring, this assumes no vertex has a loop, an edge to itself. Multiple edges between the same two vertices make no difference.)

(4) Let v be a vertex of G with degree at most 4. Delete v and its edges to get G − v. Deleting them from a crossing-free drawing of G gives a crossing-free drawing of G − v, so G − v is planar, and it has n vertices. By Statement A for n, G − v can be coloured with at most 5 colours, say from {1, 2, 3, 4, 5}. Now put v back. Its at most 4 neighbours use at most 4 of the 5 colours, so at least one colour is free. Give v that colour. No edge of G − v changed colour, and every edge at v joins two different colours, so G is coloured with at most 5 colours.

This is the easy step of the five colour theorem. The full theorem also handles a smallest degree of exactly 5 (using Kempe chains), which this question does not ask for.

In one or two sentences: The six-vertex wheel is planar but needs four colours, because its odd rim needs three and the hub touches all of them. Counting degrees with m ≤ 3n − 6 forces a vertex of degree at most 5, and a vertex of degree at most 4 can be removed, the rest coloured, and then given the free fifth colour.

Follow-ups (each builds on your last answer)

  1. Prof: "You used the fact that a planar graph has at most 3n minus 6 edges. Where does that come from?"
    You: "From Euler's formula: a connected planar drawing with n vertices, m edges and f faces has n minus m plus f equal to 2. In a simple graph with at least 3 vertices, every face is bounded by at least 3 edges and every edge touches at most 2 faces, so 3f is at most 2m. Putting f equal to 2 minus n plus m into that gives m at most 3n minus 6."
  2. Prof: "What changes if the graph has no triangles? Use it on K3,3."
    You: "Then every face has at least 4 edges, so 4f is at most 2m, and the same steps give m at most 2n minus 4. K3,3, three vertices each joined to the same other three, has no triangles because it is bipartite, and it has 6 vertices and 9 edges, but 2 times 6 minus 4 is only 8. So K3,3 is not planar."
  3. Prof: "So counting edges can prove that a graph is not planar. Can it ever miss a graph that is not planar?"
    You: "Yes, the bound is necessary but not sufficient. If I put a new vertex in the middle of every edge of K3,3, I get 15 vertices and 18 edges with no triangles, well under 2n minus 4, which is 26, but it still can't be drawn without crossings. Kuratowski's theorem says a graph is planar exactly when it contains no subdivided K5 or K3,3 like this, and in practice a program checks planarity in linear time, for example with the Hopcroft and Tarjan algorithm."

Part II: Informatics and Data Science II

Question 1

Answer the following questions (1) to (4). Let S be the following memoryless information source:

      ( s₁    s₂    s₃  )
S  =  ( 1/2   1/4   1/4 )

(symbol s₁ has probability 1/2, and s₂ and s₃ have probability 1/4 each).

(1) Calculate the numerical value of the entropy H(S) of S.

(2) Explain why the following binary code C for S is not instantaneously decodable.

S C
s₁ 0
s₂ 01
s₃ 11

(3) Calculate the average codeword length L̄ of a Huffman code for the second extension S² of S.

(4) Let U be any memoryless information source. Prove that H(U²) = 2H(U) holds for the second extension U² of U.

Answer.

(1) H(S) = −Σ pᵢ log₂ pᵢ = (1/2)(1) + (1/4)(2) + (1/4)(2) = 1.5 bits per symbol.

(2) A code is instantaneously decodable exactly when no codeword is a prefix of another codeword (the prefix condition). Here the codeword of s₁, which is 0, is a prefix of the codeword of s₂, which is 01. So when the decoder has read a 0, it cannot yet tell whether this is s₁ or the start of s₂, and it has to look at later bits.

It may have to wait a long time: 011 is s₁ s₃, but 0111 is s₂ s₃. In general, a 0 followed by k ones starts with s₁ if k is even and with s₂ if k is odd, so the first symbol is known only when the decoder reaches the next 0 or the end of the message. (The code is still uniquely decodable, because read backwards it is a prefix code, but it is not instantaneous.)

(3) S² has 9 symbols (pairs) with these probabilities:

pairs probability
s₁s₁ 1/4
s₁s₂, s₁s₃, s₂s₁, s₃s₁ 1/8 each
s₂s₂, s₂s₃, s₃s₂, s₃s₃ 1/16 each

Huffman's method: merge the four 1/16 into two of 1/8; then merge the six 1/8 into three of 1/4; then the four 1/4 into two of 1/2; then the last two into 1. The codeword lengths are 2 for s₁s₁, 3 for the four pairs of probability 1/8, and 4 for the four pairs of probability 1/16. One such code:

pair codeword pair codeword
s₁s₁ 00 s₂s₂ 1100
s₁s₂ 010 s₂s₃ 1101
s₁s₃ 011 s₃s₂ 1110
s₂s₁ 100 s₃s₃ 1111
s₃s₁ 101

L̄ = (1/4)(2) + 4 × (1/8)(3) + 4 × (1/16)(4) = 0.5 + 1.5 + 1 = 3 bits per symbol of S² (that is, 1.5 bits per original symbol).

Every probability is a power of 1/2, so each length equals −log₂ p and L̄ equals the entropy H(S²) = 3 exactly. No code can do better than the entropy, so every Huffman code for S², whatever the tie-breaking, has L̄ = 3. (Python: Huffman lengths as above, Kraft sum 1/4 + 4/8 + 4/16 = 1, L̄ = 3.)

Two facts used below: NOR(1)(x) = ¬x, so a NOR gate with one input is an inverter, and NOR(x₁, ..., xₙ) = ¬(x₁ ∨ ... ∨ xₙ).

In (2) to (4), "number of gates" counts every NOR(n) gate as one gate, whatever n is, as the question's definition allows, and circuits have no feedback loops. Constant inputs never help: a constant 1 makes a gate always output 0, and a constant 0 changes nothing.

a ──┐

(3) 4 gates. By De Morgan's law, a ∧ b ∧ c = ¬(¬a ∨ ¬b ∨ ¬c) = NOR(¬a, ¬b, ¬c).

a ── NOR(1) ──┐

Why 3 gates are not enough:

  • The output gate F cannot take a variable directly. If a went into F, then F = 0 whenever a = 1, but a ∧ b ∧ c = 1 at a = b = c = 1. So F reads only other gates g, and the OR of those g must equal ¬(a ∧ b ∧ c). That OR must be 1 on the three input rows (0,1,1), (1,0,1), (1,1,0), and 0 on (1,1,1). In particular F alone (1 gate) is impossible.
  • A gate that outputs 1 on the row (0,1,1) has all its inputs 0 there, so the only variable it can read is a. A gate that outputs 1 on two of the three rows, for example (0,1,1) and (1,0,1), can read no variable at all, so it reads only other gates.
  • F plus one gate G: F = ¬G, so G must be 1 on all three rows. Then G reads no variable, and there is no other gate for it to read (it cannot read F, since there is no feedback). Impossible.
  • F plus two gates G and H, with F reading only G: as before, G reads no variable, so G reads only H and G = ¬H. Then H alone must compute a ∧ b ∧ c from variables, which the first bullet above rules out.
  • F plus two gates G and H, with F reading both: one of them, say G, is 1 on two of the three rows, so G reads only H and G = ¬H. Then G ∨ H = 1 on every row, including (1,1,1). Impossible.

A computer search over every circuit with up to 3 NOR gates (any number of inputs) agrees: none computes a ∧ b ∧ c.

(4) 3 gates. (a ∨ b) ∧ (c ∨ d) = ¬(¬(a ∨ b) ∨ ¬(c ∨ d)) = NOR(NOR(a, b), NOR(c, d)).

a ──┐

Why 2 gates are not enough: the output gate F cannot take a variable directly (if a went into F, F would be 0 at a = c = 1, b = d = 0, where the formula is 1; the same works for b, c and d). One gate alone is therefore impossible. With 2 gates, F reads only the other gate G, and G reads only variables, so F = ¬G is an OR of some variables. But the formula is 0 whenever exactly one variable is 1, so that OR could contain no variable at all, and the formula is not constant. The computer search agrees.

(5) Two steps.

Step 1: write f with AND, OR and NOT. Take every row of the truth table where f = 0. For such a row (r₁, ..., rₙ), form the sum term (maxterm) M = l₁ ∨ ... ∨ lₙ, where lᵢ = xᵢ if rᵢ = 0 and lᵢ = ¬xᵢ if rᵢ = 1. M is 0 on that row and 1 on every other row. Then

f = M₁ ∧ M₂ ∧ ... ∧ M_k (product of sums, also called conjunctive normal form),

which is 0 exactly on the rows where f is 0.

Step 2: build every part from NOR gates.

  • NOT: ¬x = NOR(x), one NOR(1) gate.
  • ¬Mⱼ = NOR(l₁, ..., lₙ), one NOR(n) gate for each zero row.
  • f = M₁ ∧ ... ∧ M_k = ¬(¬M₁ ∨ ... ∨ ¬M_k) = NOR(¬M₁, ..., ¬M_k), one NOR(k) gate.

So f = NOR( NOR(literals of M₁), ..., NOR(literals of M_k) ), with NOR(1) gates making the negated inputs: a circuit of at most three levels that uses only NOR gates. If f has no zero row (f is always 1), use NOR(NOR(x₁, NOR(x₁))): x₁ ∨ ¬x₁ is always 1, so NOR(x₁, NOR(x₁)) is always 0, and inverting it gives 1.

Put another way: NOR alone makes NOT, OR (a NOR followed by an inverter) and AND (as in (3)), and AND, OR and NOT can express any truth table, so NOR by itself is functionally complete. The circuit in (4) has the same NOR-of-NORs shape, applied directly to the short product of sums (a ∨ b) ∧ (c ∨ d) instead of to one full maxterm per zero row, and it needs no inverters. The construction was checked in Python on all 256 functions of three inputs.

In one or two sentences: A NOR gate with one input is NOT, so OR of three inputs needs 2 gates, AND of three needs 4 (three inverters and one NOR), and (a ∨ b) ∧ (c ∨ d) needs 3. Any truth table can be written as a product of sums, and a product of sums is exactly a NOR of NORs, so NOR gates alone can build any function.

Question 5

Assume that X ~ N(μ, σ²), where N(μ, σ²) is the univariate normal (Gaussian) distribution with probability density function

p(x) = (1/√(2πσ²)) e^(−(x − μ)²/(2σ²)).

(1) Given observations x₁, x₂, ..., xₙ that are independent samples from N(μ, σ²), and assuming σ² is known, derive the maximum likelihood estimator of μ.

(2) Find ∂φ_X(t)/∂t, where φ_X(t) = e^(iμt − σ²t²/2) is the characteristic function of the univariate normal distribution.

(3) Use ∂φ_X(t)/∂t to derive E[X], the expected value of X.

Answer.

(1) The likelihood is L(μ) = Πᵢ (1/√(2πσ²)) e^(−(xᵢ − μ)²/(2σ²)), so the log-likelihood is

log L(μ) = −(n/2) log(2πσ²) − (1/(2σ²)) Σᵢ (xᵢ − μ)².

Set the derivative to 0:

d/dμ log L(μ) = (1/σ²) Σᵢ (xᵢ − μ) = 0, so Σᵢ xᵢ − nμ = 0, and

μ̂ = (1/n) Σᵢ xᵢ = x̄, the sample mean.

The second derivative is −n/σ² < 0, so this is a maximum. The known σ² does not affect the answer.

(2) By the chain rule,

∂φ_X(t)/∂t = (iμ − σ²t) e^(iμt − σ²t²/2).

(3) By definition φ_X(t) = E[e^(itX)], so ∂φ_X(t)/∂t = E[iX e^(itX)] (differentiating inside the expectation), and at t = 0 this is i E[X]. From (2), ∂φ_X/∂t at t = 0 is (iμ − 0) e⁰ = iμ. So i E[X] = iμ, and

E[X] = (1/i) ∂φ_X(t)/∂t at t = 0 = μ.

(Checked in sympy.)

In one or two sentences: Setting the derivative of the log-likelihood to zero gives the sample mean as the estimate of μ. The derivative of the characteristic function at 0 is i times the mean, and for the normal distribution it is iμ, so E[X] = μ.

Question 6

(1) Explain in your own words the purpose of the K-fold cross-validation algorithm and how this algorithm works.

(2) Explain the following machine learning terms:

  • (a) "feature extraction", "feature vector" and "feature space";
  • (b) "activation functions" used in neural networks (explain why activation functions are needed, and give at least two examples of commonly used activation functions).

Answer.

(1) Purpose. K-fold cross-validation estimates how well a model will work on data it has not seen. It uses all the data for both training and checking, and the estimate is used to compare models or to choose settings (hyperparameters) such as the degree of a polynomial, k in k-nearest neighbours, or the strength of regularisation. With a single split into training and validation data, the estimate depends on which samples happened to land in the validation part, and that part is never used for training. K-fold cross-validation reduces both problems.

How it works.

  1. Shuffle the data and split it into K parts (folds) of about equal size. For classification, the folds are often stratified so that each has the same class proportions.
  2. For each k = 1, ..., K: train the model on the other K − 1 folds, then measure its error (or accuracy) eₖ on fold k, which it did not see during training.
  3. Report the average (1/K) Σ eₖ as the cross-validation estimate, often with its standard deviation.
  4. After choosing the model or the setting, train it once more on all the data.

Every sample is used for checking exactly once and for training K − 1 times. Common choices are K = 5 or K = 10; K = n (one sample per fold) is called leave-one-out. The cost is K separate trainings. If a separate test set is kept for the final result, it must stay outside the cross-validation.

(2)(a)

  • Feature extraction is turning raw data into a small number of informative values (features) that describe what matters for the task, and dropping the rest. Examples: colour histograms or edge and texture measures from an image, MFCCs from audio, word counts or TF-IDF from text. Features can be designed by hand or learned (for example by PCA, or by the hidden layers of a convolutional neural network). Good features make learning easier and reduce the number of dimensions.
  • A feature vector is the list of feature values for one sample, written as a vector x = (x₁, ..., x_d)ᵀ. For example, (height, weight, age) for a person.
  • The feature space is the d-dimensional space (usually ℝ^d) in which the feature vectors live. Each sample is a point in it, and similar samples lie close together. A classifier divides the feature space into regions separated by decision boundaries, and methods such as k-nearest neighbours and clustering work with distances in this space.

(2)(b) In a neural network, each neuron computes a weighted sum u = wᵀx + b and passes it through an activation function, giving the output h = φ(u).

Why they are needed. Without a non-linear activation function, every layer is a linear (affine) map, and a chain of linear maps is still linear: W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂). So a deep network would be no more powerful than a single linear layer and could not learn non-linear patterns such as XOR. Non-linear activation functions let a network with hidden layers approximate any continuous function (the universal approximation theorem). They should be differentiable (at least almost everywhere) so that backpropagation can compute gradients. At the output layer they also put values into a useful range, for example a probability between 0 and 1.

Examples (at least two are asked for):

  • Sigmoid: σ(u) = 1/(1 + e^(−u)), with values in (0, 1) and derivative σ(u)(1 − σ(u)). It flattens out for large |u|, which makes gradients vanish in deep networks.
  • tanh: tanh(u) = (eᵘ − e^(−u))/(eᵘ + e^(−u)), with values in (−1, 1) and centred at 0.
  • ReLU: ReLU(u) = max(0, u). It is cheap and has gradient 1 for u > 0, so deep networks train well with it; it is the most common choice for hidden layers. Variants include Leaky ReLU and GELU.
  • Softmax, for the output layer in classification with several classes: yₖ = e^(uₖ) / Σⱼ e^(uⱼ), which turns the raw outputs into probabilities that add up to 1.

In one or two sentences: K-fold cross-validation trains K times, each time holding out a different fold for checking, and averages the K results to estimate how the model does on new data. Features turn raw data into a vector, a point in feature space, and activation functions add the non-linearity without which a deep network would collapse into one linear map.

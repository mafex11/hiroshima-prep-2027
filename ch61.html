Part 2. Research plan

Slide 8. Voting needs versions that fail differently

  • Card Zheng, Okamura, Dohi [1]: Voting made strong models more reliable, but helped little with weak ones.
  • Card Ron et al. [5]: 429 inputs out of a million, vs ≈ 115 if independent
  • Dark band: Neither 2026 study [5, 6] used a context file.

Slide 9. Two questions: shared failures and one rule

  • RQ1: How much more often do runs fail together than independence predicts? Which change lowers it most?
  • RQ2: Does replacing one real rule with neutral text change reliability, on the PR's tests and beyond them?

Slide 10. Method: repeated runs on real tasks

  • Five steps: Task merged PR [8] → File original / one rule replaced → Run 10 times → Admit passes PR's tests → Test 10,000+ random inputs
  • 820 runs · ≈ 420 to 590 USD, "cost, at the per-task costs in [8]"

Slide 11. One number for "fail together"

  • Formula box: P(two runs both fail) = p² + Var θ(X) [11]
  • Strip: Beta-binomial ρ: 0 = independent
  • Picture, "Same p = 0.2": "Equally hard" (eight bars at 0.2) → both fail: 0.04 · "Half easy, half hard" (four bars at 0, four at 0.4) → both fail: 0.08. The bars are θ(x), the failure chance at one input x.

Slide 12. Two years, two results, all data public

  • Year 1: Courses, harness, pilot · Main runs, RQ2
  • Year 2: Model, RQ1, first paper · Thesis
  • Three results: Fitted model · One rule's effect · Open data

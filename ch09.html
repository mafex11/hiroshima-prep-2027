January 2024: questions and answers

When and how long: If time.

This is our own English version of the question set the Informatics and Data Science Program at Hiroshima University used on 25 January 2024, for students starting in April 2024. Part I (four questions) is maths: linear algebra, a maximum and minimum on a sphere, the exponential distribution, and sets and relations. Part II (seven questions) covers information theory, graph colouring, a C program, Boolean functions, regression and the z-test, machine learning, and a short write-up of your own research.

How this file was made: every question was translated from the Japanese and English original, and every figure is described in words. Every numeric result and truth table was recomputed in Python (numpy, sympy, networkx) on 13 Nov 2026, and the C program was compiled and run. Anything I am not fully sure of is marked [CHECK] and listed at the end.

Notation: ^ is a power, ^T is a transpose, √ is a square root, log2 is log base 2, and a' means NOT a in Question 4 of Part II.

Part I: Informatics and Data Science I

Question 1

(1) Let

A = [ 1  1   1 ]
    [ 1  0  -1 ]

Define the linear map f: R^3 → R^2 by x → y = f(x) = Ax (x ∈ R^3, y ∈ R^2).

  • (1-1) Find the dimension of the image Im f and one basis of it.
  • (1-2) Find the dimension of the kernel Ker f and one basis of it.

(2) Let B be a 3 × 3 real symmetric matrix that satisfies (i) and (ii):

  • (i) The eigenvalues of B are λ1 = -1, λ2 = 5 and λ3 = 3.

  • (ii) u2 = (1, 1, 1)^T and u3 = (1, 0, -1)^T are eigenvectors for λ2 and λ3, respectively.

  • (2-1) Find an eigenvector u1 for the eigenvalue λ1 = -1.

  • (2-2) Find the matrix B.

Answer.

(1-1) The two rows of A are not multiples of each other, so rank A = 2. The image is spanned by the columns (1, 1)^T, (1, 0)^T and (1, -1)^T, and the first two are already independent. So Im f is all of R^2.

  • dim Im f = 2. One basis: {(1, 1)^T, (1, 0)^T}. The standard basis {(1, 0)^T, (0, 1)^T} is also right.

(1-2) Solve Ax = 0:

x1 + x2 + x3 = 0
x1      - x3 = 0      so  x1 = x3  and  x2 = -2 x3

So Ker f = { t (1, -2, 1)^T : t ∈ R }.

  • dim Ker f = 1. One basis: {(1, -2, 1)^T}. Check: rank + nullity = 2 + 1 = 3, the dimension of R^3.

(2-1) For a real symmetric matrix, eigenvectors for different eigenvalues are orthogonal. So u1 must be orthogonal to both u2 and u3. The cross product gives such a vector:

u2 × u3 = (1, 1, 1) × (1, 0, -1)
        = (1·(-1) - 1·0,  1·1 - 1·(-1),  1·0 - 1·1)
        = (-1, 2, -1)

So u1 = (1, -2, 1)^T (any non-zero multiple is also right). Check: u1·u2 = 1 - 2 + 1 = 0 and u1·u3 = 1 + 0 - 1 = 0.

(2-2) Use the spectral decomposition B = Σ λi ui ui^T / (ui^T ui):

B = -1 · (1/6) [  1 -2  1 ]  + 5 · (1/3) [ 1 1 1 ]  + 3 · (1/2) [  1  0 -1 ]
               [ -2  4 -2 ]              [ 1 1 1 ]              [  0  0  0 ]
               [  1 -2  1 ]              [ 1 1 1 ]              [ -1  0  1 ]

Entry by entry, for example b11 = -1/6 + 5/3 + 3/2 = 3, b12 = 2/6 + 5/3 + 0 = 2, b13 = -1/6 + 5/3 - 3/2 = 0, b22 = -4/6 + 5/3 + 0 = 1. The result is

B = [ 3  2  0 ]
    [ 2  1  2 ]
    [ 0  2  3 ]

Check: B u1 = (-1, 2, -1)^T = -u1, B u2 = (5, 5, 5)^T = 5 u2, B u3 = (3, 0, -3)^T = 3 u3, and the trace 3 + 1 + 3 = 7 equals -1 + 5 + 3. sympy gives the same rank, kernel, B and eigenvalues.

Side note: the rows of A are exactly u2 and u3. So Ker f in (1-2) is the set of vectors orthogonal to u2 and u3, which is why the same vector (1, -2, 1) appears twice.

In one or two sentences: The image of f is all of R^2 and the kernel is the line through (1, -2, 1). For a symmetric matrix, eigenvectors for different eigenvalues are orthogonal, so u1 = (1, -2, 1), and B is the sum of each eigenvalue times the projection onto its eigenvector.

Question 2

Find the maximum and minimum values of the function f(x, y, z) = (x + y) √(z^2 + 1) on the sphere x^2 + y^2 + z^2 = 1.

Answer.

Fix z with -1 ≤ z ≤ 1. Then x^2 + y^2 = 1 - z^2. By the Cauchy-Schwarz inequality,

|x + y| ≤ √2 · √(x^2 + y^2) = √(2(1 - z^2)),     with equality when x = y.

So

|f| ≤ √(2(1 - z^2)) · √(1 + z^2) = √(2(1 - z^4)) ≤ √2,

and the last step is an equality only when z = 0.

  • At (x, y, z) = (1/√2, 1/√2, 0), f = √2. Maximum: √2.
  • At (x, y, z) = (-1/√2, -1/√2, 0), f = -√2. Minimum: -√2.

Check: Lagrange multipliers (grad f = 2μ (x, y, z) together with the constraint) give exactly these two solutions in sympy. A random search over 2 million random positions on the sphere gave a largest value of 1.41421 and a smallest of -1.41421, and √2 ≈ 1.41421.

In one or two sentences: For a fixed height z, x + y is largest when x = y, which turns f into √(2(1 - z^4)). That is largest at z = 0, so the maximum is √2 and the minimum is -√2.

Question 3

X1, X2, ..., Xn are independent random variables, all exponentially distributed with the same parameter λ (> 0). The probability density function of Xj (j = 1, 2, ..., n) is

f(x) = λ e^(-λx)    for 0 < x < ∞
       0            otherwise
  • (1) Find the probability distribution function of Xj (j = 1, 2, ..., n), Pr{Xj ≤ x}.
  • (2) Find the mean E[Xj] and the variance Var[Xj].
  • (3) Find the probability distribution function of the maximum Y = max{X1, X2, ..., Xn}.
  • (4) Find the probability distribution function of the minimum Z = min{X1, X2, ..., Xn}.
  • (5) Find the probability density function of the sum of two of the random variables, Xj + Xj+1 (j = 1, 2, ..., n - 1).

Answer.

(1)

F(x) = Pr{Xj ≤ x} = ∫_0^x λ e^(-λt) dt = 1 - e^(-λx)    for x > 0,   and 0 for x ≤ 0.

(2) Integrate by parts:

E[Xj]   = ∫_0^∞ x λ e^(-λx) dx   = 1/λ
E[Xj^2] = ∫_0^∞ x^2 λ e^(-λx) dx = 2/λ^2
Var[Xj] = 2/λ^2 - (1/λ)^2        = 1/λ^2

(3) Y ≤ y exactly when every Xi ≤ y. By independence,

Pr{Y ≤ y} = Pr{X1 ≤ y} · Pr{X2 ≤ y} ··· Pr{Xn ≤ y} = (1 - e^(-λy))^n    for y > 0,   and 0 for y ≤ 0.

(4) Z > z exactly when every Xi > z. So

Pr{Z > z} = (e^(-λz))^n = e^(-nλz)
Pr{Z ≤ z} = 1 - e^(-nλz)    for z > 0,   and 0 for z ≤ 0.

The minimum is again exponential, with parameter nλ.

(5) Xj and Xj+1 are independent, so the density of S = Xj + Xj+1 is the convolution of the two densities:

g(s) = ∫_0^s λ e^(-λx) · λ e^(-λ(s - x)) dx = λ^2 e^(-λs) ∫_0^s dx = λ^2 s e^(-λs)    for s > 0,   and 0 otherwise.

This is the gamma (Erlang) distribution with shape 2 and rate λ.

Check: sympy gives the same distribution function, mean, variance and convolution. A simulation with λ = 1.7, n = 5 and 400,000 samples matched the formulas in (1), (3) and (4) to within 0.001 at x = 0.3, 0.8 and 1.5, the mean (0.5880 against 1/λ = 0.5882) and the variance (0.3463 against 1/λ^2 = 0.3460), and the histogram of the sum followed λ^2 s e^(-λs) to within 0.012.

In one or two sentences: For the maximum, all n values must be below y, so you multiply the distribution functions. For the minimum, all must be above z, which gives another exponential with rate nλ, and the sum of two independent exponentials has density λ^2 s e^(-λs).

Question 4

For sets X and Y, the set X × Y = {(x, y) | x ∈ X, y ∈ Y} is called the Cartesian product of X and Y. For a non-empty set X, a subset R of X × X is called a binary relation on X, and aRb means (a, b) ∈ R. A binary relation R on a non-empty set X is called an equivalence relation if it satisfies (i) to (iii):

  • (i) For any x ∈ X, xRx.
  • (ii) For any x, y ∈ X, if xRy then yRx.
  • (iii) For any x, y, z ∈ X, if xRy and yRz then xRz.

Answer the following.

  • (1) For X = {0, 1, 2} and Y = {a, b}, list all elements of X × Y.
  • (2) Let X = {0, 1, 2}. Give one binary relation on X that is neither an equivalence relation nor the empty set, with the reason.
  • (3) For an equivalence relation R on a non-empty set X and x ∈ X, define [x]_R = {y ∈ X | xRy}. Prove that (A) and (B) hold for any equivalence relation R on any non-empty set X.
    • (A) For any x, y ∈ X, if xRy then [x]_R = [y]_R.
    • (B) For any x, y ∈ X, if [x]_R ≠ [y]_R then [x]_R ∩ [y]_R = ∅.

Answer.

(1) X × Y = {(0, a), (0, b), (1, a), (1, b), (2, a), (2, b)}, that is 3 × 2 = 6 elements.

(2) R = {(0, 1)}. It is not empty. It is not an equivalence relation because (i) fails: (0, 0) is not in R, so 0R0 is false. (It also breaks (ii): 0R1 holds but 1R0 does not.)

(3)

(A) Assume xRy.

  • [x]_R ⊆ [y]_R: take z ∈ [x]_R, so xRz. From xRy and (ii), yRx. From yRx, xRz and (iii), yRz. So z ∈ [y]_R.
  • [y]_R ⊆ [x]_R: take z ∈ [y]_R, so yRz. From xRy, yRz and (iii), xRz. So z ∈ [x]_R.

Both inclusions hold, so [x]_R = [y]_R.

(B) Prove the contrapositive: if [x]_R ∩ [y]_R ≠ ∅, then [x]_R = [y]_R. Take z in the intersection, so xRz and yRz. By (ii), zRy. By (iii) with xRz and zRy, xRy. Then (A) gives [x]_R = [y]_R. So if [x]_R ≠ [y]_R, the two classes have no common element.

Check: Python lists the same six pairs, and confirms that R = {(0, 1)} is not reflexive and not symmetric.

In one or two sentences: An equivalence relation splits the set into classes. If two elements are related they have the same class, and two different classes never overlap, which you prove with symmetry and transitivity.

Part II: Informatics and Data Science II

Question 1

Figure 1 shows a binary symmetric erasure channel. In the figure, the symbol e means that a symbol sent from X was erased on its way to Y. Answer (1) to (4). The probabilities of the symbols in X are P(x1) = r and P(x2) = 1 - r.

Figure 1 ("A binary symmetric erasure channel"), in words: the inputs X are on the left (x1 = 0 at the top, x2 = 1 at the bottom), the outputs Y are on the right (y1 = 0 at the top, y2 = e in the middle, y3 = 1 at the bottom), and there is an arrow from every input to every output, labelled with its probability:

x1 = 0  --(1 - p - q)-->  y1 = 0
x1 = 0  --(q)---------->  y2 = e   (erased)
x1 = 0  --(p)---------->  y3 = 1
x2 = 1  --(p)---------->  y1 = 0
x2 = 1  --(q)---------->  y2 = e   (erased)
x2 = 1  --(1 - p - q)-->  y3 = 1

So each input arrives correctly with probability 1 - p - q, is erased with probability q, and flips to the other bit with probability p.

  • (1) Write the probabilities (a) and (b) in terms of p and q, or p, q and r.
    • (a) P(y3 | x2)
    • (b) P(y3)
  • (2) Write the conditional entropy H(Y|X) = - Σ_{i=1}^{2} P(xi) Σ_{j=1}^{3} P(yj | xi) log2 P(yj | xi) in terms of p and q.
  • (3) Write the mutual information I(X;Y) = H(Y) - H(Y|X) in terms of p, q and r.
  • (4) Write the channel capacity C of the channel in Figure 1 in terms of p and q.

Answer.

(1)(a) P(y3 | x2) = 1 - p - q (the arrow from 1 to 1).

(1)(b) P(y3) = P(x1) P(y3 | x1) + P(x2) P(y3 | x2) = r p + (1 - r)(1 - p - q).

(2) Both inputs have the same three probabilities {1 - p - q, q, p}, so the inner sum is the same for i = 1 and i = 2, and r + (1 - r) = 1:

H(Y|X) = -(1 - p - q) log2(1 - p - q) - p log2 p - q log2 q

(3) The output probabilities are

P(y1) = r(1 - p - q) + (1 - r) p
P(y2) = q
P(y3) = r p + (1 - r)(1 - p - q)

H(Y) = -Σ P(yj) log2 P(yj). Subtracting H(Y|X), the q log2 q terms cancel:

I(X;Y) = -[r(1 - p - q) + (1 - r)p] log2[r(1 - p - q) + (1 - r)p]
         -[rp + (1 - r)(1 - p - q)] log2[rp + (1 - r)(1 - p - q)]
         + (1 - p - q) log2(1 - p - q) + p log2 p

(4) C = the maximum of I(X;Y) over r. H(Y|X) does not depend on r, and P(y2) = q is fixed. So we only need to make -P(y1) log2 P(y1) - P(y3) log2 P(y3) as large as possible, with P(y1) + P(y3) = 1 - q fixed. That is largest when P(y1) = P(y3) = (1 - q)/2. Since P(y1) - P(y3) = (2r - 1)(1 - 2p - q), this happens at r = 1/2. Then

H(Y) = -(1 - q) log2((1 - q)/2) - q log2 q = (1 - q) - (1 - q) log2(1 - q) - q log2 q

C = (1 - q) - (1 - q) log2(1 - q) + (1 - p - q) log2(1 - p - q) + p log2 p
  = (1 - q) [ 1 - h( p / (1 - q) ) ],     where h(t) = -t log2 t - (1 - t) log2(1 - t)

Quick checks: q = 0 gives 1 - h(p), the binary symmetric channel. p = 0 gives 1 - q, the binary erasure channel.

Check in Python: for (p, q) = (0.1, 0.2), (0.05, 0.3), (0.2, 0.1) and (0, 0.25), a search over r found the largest I(X;Y) at r = 0.5, equal to the formula each time (C = 0.3651, 0.4401, 0.2122 and 0.75 bits). The formulas for P(y1), P(y3) and H(Y|X) also matched a direct computation from the double sum.

In one or two sentences: The noise part H(Y|X) is the same for both inputs, so capacity comes from making the outputs as spread out as possible, and a uniform input (r = 1/2) does that. The answer is C = (1 - q)(1 - h(p/(1 - q))): the share of symbols that are not erased, times the capacity of the bit-flip channel that is left.

Question 2

For an undirected graph G = (V, E), a function c: V → {0, 1, ..., k - 1} with c(u) ≠ c(v) for every edge (u, v) ∈ E is called a k-colouring. G is called k-colourable if a k-colouring of G exists. Answer the following.

  • (1) Show that graph G1 is 4-colourable.
  • (2) Prove that every tree is 2-colourable.
  • (3) Let Δ be the maximum degree of an undirected graph G. Prove that G is (Δ + 1)-colourable.
  • (4) When the maximum degree is Δ, show two distinct connected graphs that are both (Δ + 1)-colourable and not Δ-colourable.

Graph G1, in words: 12 vertices numbered 1 to 12, drawn inside a large triangle whose corners are 1 (top), 11 (bottom left) and 12 (bottom right). Vertex 2 is straight below 1. Vertices 3 and 4 are below 2, on the left and right. Vertices 5 and 6 are side by side in the middle, 7 is below them, 8 and 9 are lower left and lower right, and 10 is at the bottom centre. The 30 edges are:

1-2    1-3    1-4    1-11   1-12
2-3    2-4    2-5    2-6
3-5    3-8    3-11
4-6    4-9    4-12
5-6    5-7    5-8
6-7    6-9
7-8    7-9    7-10
8-10   8-11
9-10   9-12
10-11  10-12
11-12

Every vertex has degree 5. This is the graph of the icosahedron: 12 vertices, 30 edges, 20 triangles (Python confirms it is isomorphic to networkx's icosahedral graph, and planar).

Answer.

(1) One 4-colouring, with colours 0 to 3:

Colour Vertices
0 1, 5, 9
1 2, 7, 11
2 3, 4, 10
3 6, 8, 12

No edge in the list joins two vertices with the same colour (Python checked all 30 edges). So G1 is 4-colourable. G1 is planar, so the four colour theorem also says this, but the question wants an actual colouring.

Side note: 3 colours are not enough. The neighbours of vertex 1 are 2, 4, 12, 11 and 3, and they form the cycle 2-4-12-11-3-2 of odd length 5. An odd cycle needs 3 colours, and vertex 1 is joined to all of them, so it needs a fourth. A full search in Python also finds no 3-colouring.

(2) Induction on the number of vertices n. A tree with n = 1 has no edges, so one colour is enough. For n ≥ 2, a tree T has a leaf v (a vertex of degree 1) with a single neighbour u. T - v is a tree with n - 1 vertices, so by induction it has a 2-colouring c. Give v the colour 1 - c(u). The only edge at v is (u, v), and its two ends now have different colours. So T is 2-colourable.

(Another way: pick a root and colour each vertex by whether its distance from the root is even or odd. Every edge joins a parent and a child whose distances differ by 1.)

(3) Greedy colouring with the colours {0, 1, ..., Δ}. Order the vertices v1, v2, ..., vn and colour them one at a time. When vi is coloured, at most Δ of its neighbours already have colours, because it has at most Δ neighbours. They use at most Δ of the Δ + 1 colours, so at least one colour is free. Give it to vi. No edge ever gets the same colour at both ends, so G is (Δ + 1)-colourable.

(4)

  • The complete graph K_(Δ+1): Δ + 1 vertices, all joined to each other, so every vertex has degree Δ. All Δ + 1 vertices are pairwise adjacent, so they need Δ + 1 different colours: it is not Δ-colourable. By (3) it is (Δ + 1)-colourable.
  • An odd cycle C_(2m+1) (m ≥ 1), where Δ = 2. With two colours, the colours must alternate around the cycle, and after an odd number of steps you come back to the start with the wrong colour, so it is not 2-colourable. Giving one vertex a third colour fixes it, so it is 3-colourable. For Δ = 2, C3 and C5 are two distinct examples.

Python confirms that K4, K5 and K6 need 4, 5 and 6 colours, and that C3, C5 and C7 need 3.

Brooks' theorem says these are the only kinds: a connected graph with maximum degree Δ is Δ-colourable unless it is a complete graph or an odd cycle. So the two graphs to give are the complete graph and the odd cycle. For a fixed Δ ≥ 3 only K_(Δ+1) works, and for Δ = 2 the odd cycles C3 (which is also K3) and C5 are two concrete examples.

In one or two sentences: Greedy colouring always works with Δ + 1 colours, because each vertex has at most Δ neighbours. The connected graphs that really need all Δ + 1 colours are complete graphs and odd cycles (Brooks' theorem), and G1, the icosahedron, needs exactly 4.

Question 3

Listing 1 is a C program that uses pointers to reverse a list. The list is defined with the structure struct Node. The function printList prints the contents of the list from the start. The function reverseListL reverses the list with a loop. The function reverseListR reverses the list with recursion. Answer (1) to (3).

  • (1) Fill in the blanks (1-1) and (1-2) in Listing 1.
  • (2) Show the output of Listing 1.
  • (3) From items (A) to (F) below, choose all that describe what happens when repeated processing is written as recursion.
    • (A) The risk of stack overflow is low.
    • (B) When mathematical induction applies, the code can express the essence of the problem concisely, which may make it easier to read.
    • (C) Because of the overhead of function calls, it often runs slower.
    • (D) When it processes a large amount of data, a stack overflow may happen.
    • (E) The code tends to become longer and may be harder to read.
    • (F) In many cases it runs faster.

Listing 1 (program code). The two blanks are boxes in the original; here they are written [ (1-1) ] and [ (1-2) ]. The original numbers the lines 1 to 71 (blank lines included, as here) and draws each space inside a string as ␣; here those are plain spaces.

#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node* next;
};

void printList(struct Node* node) {
    while (node != NULL) {
        printf("%d ", [ (1-1) ]);
        node = [ (1-2) ];
    }
    printf("\n");
}

struct Node* reverseListL(struct Node* head) {
    struct Node* prev = NULL;
    struct Node* current = head;
    struct Node* next = NULL;
    while (current != NULL) {
        printf("current: ");
        printList(current);
        next = current->next;
        current->next = prev;
        prev = current;
        current = next;
        printf("prev: ");
        printList(prev);
    }
    return prev;
}

struct Node* reverseListR(struct Node* head) {
    printf("head: ");
    printList(head);
    if (head == NULL || head->next == NULL) {
        return head;
    }
    struct Node* rest = reverseListR(head->next);
    head->next->next = head;
    head->next = NULL;
    printf("rest: ");
    printList(rest);
    return rest;
}

int main() {
    struct Node* head = NULL;
    struct Node* second = NULL;
    struct Node* third = NULL;

    head = (struct Node*)malloc(sizeof(struct Node));
    second = (struct Node*)malloc(sizeof(struct Node));
    third = (struct Node*)malloc(sizeof(struct Node));

    head->data = 1;
    head->next = second;
    second->data = 2;
    second->next = third;
    third->data = 3;
    third->next = NULL;

    printList(head);
    head = reverseListL(head);
    printList(head);
    head = reverseListR(head);
    printList(head);

    return 0;
}

Answer.

(1) (1-1) node->data and (1-2) node->next.

(2) The output (each number is followed by one space):

1 2 3
current: 1 2 3
prev: 1
current: 2 3
prev: 2 1
current: 3
prev: 3 2 1
3 2 1
head: 3 2 1
head: 2 1
head: 1
rest: 1 2
rest: 1 2 3
1 2 3

How it comes out:

  • printList(head) prints 1 2 3.

Question 5

Consider two populations A and B, both normally distributed, with means μA and μB, respectively, and a common, known variance σ^2. Suppose we have a sample of size n from each population: {a1, ..., an} (population A) and {b1, ..., bn} (population B). We want to run an independent-samples z-test of H0: μA = μB against H1: μA ≠ μB. We will run this test with the simple linear regression model yi = xi^T β + εi (i = 1, ..., 2n), where εi ~ N(0, σ^2), β = (β1, β2)^T, and

    [ x1^T     ]   [ 1  0 ]              [ y1     ]   [ a1  ]
    [  ...     ]   [ ...  ]              [  ...   ]   [ ... ]
X = [ xn^T     ] = [ 1  0 ]    and   y = [ yn     ] = [ an  ]
    [ x(n+1)^T ]   [ 1  1 ]              [ y(n+1) ]   [ b1  ]
    [  ...     ]   [ ...  ]              [  ...   ]   [ ... ]
    [ x2n^T    ]   [ 1  1 ]              [ y2n    ]   [ bn  ]

(The first n rows of X are (1, 0) and the last n rows are (1, 1).)

  • (1) Compute β̂, the least squares estimate of β, using β̂ = (X^T X)^(-1) X^T y.
  • (2) Compute E(β̂2), the expected value of β̂2.
  • (3) Compute Var(β̂2), the variance of β̂2.
  • (4) Knowing that β̂2 is normally distributed, what is the formula of the test statistic for H0: μA = μB against H1: μA ≠ μB? What is the sampling distribution of this test statistic?

Answer.

Write ā = (a1 + ... + an)/n and b̄ = (b1 + ... + bn)/n.

(1)

X^T X = [ 2n  n ]          X^T y = [ n ā + n b̄ ]
        [  n  n ]                  [ n b̄       ]

det = 2n^2 - n^2 = n^2,    (X^T X)^(-1) = (1/n) [  1  -1 ]
                                                [ -1   2 ]

β̂ = (1/n) [  1  -1 ] [ n(ā + b̄) ]  =  [ ā     ]
          [ -1   2 ] [ n b̄      ]     [ b̄ - ā ]

So β̂1 = ā and β̂2 = b̄ - ā. This makes sense: for group A the model says y = β1 + ε, and for group B it says y = β1 + β2 + ε, so β1 is the mean of A and β2 is the difference between the two means.

(2) E(ā) = μA and E(b̄) = μB, so E(β̂2) = μB - μA. β̂2 is unbiased for β2 = μB - μA.

(3) ā and b̄ are independent, each with variance σ^2/n, so Var(β̂2) = σ^2/n + σ^2/n = 2σ^2/n. The same comes from σ^2 (X^T X)^(-1), whose (2, 2) entry is 2σ^2/n.

(4) Under H0, μB - μA = 0, so the statistic is

Z = β̂2 / √Var(β̂2) = (b̄ - ā) / (σ √(2/n))

Under H0, Z follows the standard normal distribution N(0, 1). At significance level α, reject H0 when |Z| > z_(α/2) (for α = 0.05, when |Z| > 1.96). Because σ is known, no t distribution is needed.

Check: sympy gives the same (X^T X)^(-1) and determinant n^2. With n = 8, μA = 1, μB = 1.6 and σ = 0.7, the least squares fit gave exactly (ā, b̄ - ā), and 100,000 simulated samples gave E(β̂2) ≈ 0.5999 (true value 0.6) and Var(β̂2) ≈ 0.1235 (true value 2σ^2/n = 0.1225). With equal means, the simulated Z had mean ≈ -0.002 and variance ≈ 0.993, and |Z| > 1.96 in 4.9% of the samples.

In one or two sentences: With a 0/1 group column, the regression slope is just b̄ - ā, with mean μB - μA and variance 2σ^2/n. Dividing it by its standard deviation gives the usual two-sample z statistic, which is N(0, 1) when the two means are equal.

Question 6

  • (1) Answer the following questions on overfitting in machine learning.
    • (a) Explain what overfitting is.
    • (b) Explain the main causes of overfitting.
    • (c) Describe at least 3 different approaches that can be used to avoid overfitting.
  • (2) Explain the differences between supervised learning and unsupervised learning. Also explain, in your own words, how one supervised learning algorithm and one unsupervised learning algorithm work (more than 100 words per algorithm; the Japanese version asks for at least 150 characters per algorithm).

Answer.

(1)(a) Overfitting means a model learns the training data too closely, including its noise and accidents, instead of the general pattern. It does very well on the training data but badly on new data. You see it as a gap: the training error keeps going down while the validation error goes up.

(1)(b) Main causes:

  • The model is too complex for the amount of data (too many parameters, too deep a tree, too high a polynomial degree).
  • Too little training data, or data that does not represent the cases the model will meet later.
  • Noisy data or wrong labels, which a flexible model memorises.
  • Too many features, many of them irrelevant.
  • Training for too long (for example, too many epochs of a neural network).

(1)(c) Ways to avoid it (any three are enough):

  • Get more data, or use data augmentation.
  • Regularisation: add a penalty on large weights (L2 or ridge, L1 or lasso, weight decay).
  • Use a simpler model or fewer features (feature selection, pruning a decision tree).
  • Early stopping: watch the error on a validation set and stop when it starts to rise.
  • Dropout in neural networks.
  • Cross-validation to choose the model and its hyperparameters.
  • Ensembles such as bagging or random forests, which average many models.

(2) The difference. In supervised learning, every training example has an input and the correct output (a label). The model learns a map from inputs to outputs, for classification or regression, and you can measure its error against the known answers. In unsupervised learning there are no labels. The algorithm looks for structure in the inputs alone, such as clusters, a lower-dimensional representation, or the shape of the distribution. There is no single right answer to compare with, so the results are harder to judge.

A supervised algorithm: logistic regression (about 170 words). Logistic regression is a supervised method for classification into two classes, for example deciding whether an email is spam. Each training example has a feature vector x and a label y that is 0 or 1. The model computes a weighted sum z = w^T x + b and puts it through the sigmoid function σ(z) = 1/(1 + e^(-z)), which turns any number into a value between 0 and 1. This value is read as the probability that y = 1. Training chooses the weights w and the bias b that make the observed labels most likely, which is the same as minimising the cross-entropy (log loss). There is no closed-form solution, so the weights are found step by step with gradient descent or Newton's method. To predict for a new example, we compute σ(w^T x + b) and say class 1 if it is above 0.5. The decision boundary w^T x + b = 0 is a straight line or plane, and each weight shows how its feature changes the log-odds.

An unsupervised algorithm: k-means clustering (about 160 words). k-means is an unsupervised method that splits data into k groups (clusters) without any labels. We choose k in advance. The algorithm starts by picking k initial centres, for example k random samples from the data. Then it repeats two steps. In the assignment step, each sample is assigned to its nearest centre, usually by Euclidean distance. In the update step, each centre is moved to the mean of the samples assigned to it. Neither step can raise the total squared distance from the samples to their centres, so the algorithm stops after a finite number of iterations, when no assignment changes. The result depends on the starting centres and can be a local minimum, so in practice we run it several times from different starts (or use k-means++ to choose them) and keep the best run. k-means works best when the clusters are round and of similar size, and k can be chosen with the elbow method or the silhouette method.

In one or two sentences: Overfitting is memorising the training data instead of learning the pattern, and you fight it with more data, simpler models, regularisation, early stopping or dropout. Supervised learning learns from labelled examples, as logistic regression does; unsupervised learning finds structure without labels, as k-means does.

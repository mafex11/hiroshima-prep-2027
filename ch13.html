Older sample set (Information Engineering, about 2014 to 2016): questions and answers

When and how long: Optional.

This is our own English version of an older sample question set in Information Engineering from Hiroshima University's Graduate School of Engineering (master's programs), from about 2014 to 2016, with a worked answer after every question. Part I has six questions (linear algebra, calculus, probability, statistics, counting, binary trees), and Part II has six (information theory, formal grammars, C programming, digital circuits, Laplace transforms, and a short writing task).

Every number below was recomputed in Python. The grammars in Part II, Question 2 were checked against every string up to length 10, and the C program in Part II, Question 3 was compiled and run with the blanks filled in. Anything uncertain is marked [CHECK].

Part I: Information Engineering I

Question 1: eigenvalues, diagonalisation and a basis of ℝ⁴

For a real matrix M, Mᵀ denotes the transpose of M. Let

    | 1  1   1 |
A = | 0  √3  0 |          Aᵀ = | 1  0   1  0 |
    | 1  0   0 |               | 1  √3  0  0 |
    | 0  0   1 |               | 1  0   0  1 |

So A is a 4 × 3 matrix and Aᵀ is 3 × 4.

(1) Find the eigenvalues λ₁, λ₂, λ₃ (λ₁ > λ₂ > λ₃) of the 3 × 3 matrix AᵀA.

(2) Find one pair of a diagonal matrix D and an orthogonal matrix U such that Uᵀ(AᵀA)U = D.

(3) Write the orthogonal matrix U found in (2) as U = (u₁ u₂ u₃), and let

v₁ = Au₁, v₂ = Au₂, v₃ = Au₃.

Let v₄ be a nonzero vector with Aᵀv₄ = 0. Prove that all four vectors v₁, v₂, v₃, v₄ in the 4-dimensional real vector space ℝ⁴ are eigenvectors of the 4 × 4 matrix AAᵀ.

(4) Prove that {v₁, v₂, v₃, v₄} is a basis of ℝ⁴.

Answer.

(1) Entry (i, j) of AᵀA is the dot product of columns i and j of A. The columns are (1, 0, 1, 0), (1, √3, 0, 0) and (1, 0, 0, 1). So

      | 2  1  1 |
AᵀA = | 1  4  1 |
      | 1  1  2 |

The characteristic polynomial is

det(λI − AᵀA) = λ³ − 8λ² + 17λ − 10 = (λ − 5)(λ − 2)(λ − 1).

(A quick way to see it: AᵀA − I has rows (1, 1, 1), (1, 3, 1), (1, 1, 1). Two rows are equal, so λ = 1 is an eigenvalue. The trace is 8 and the determinant is 10, so the other two eigenvalues add to 7 and multiply to 10. They are 5 and 2.)

So λ₁ = 5, λ₂ = 2, λ₃ = 1.

(2) Solve (AᵀA − λI)x = 0 for each eigenvalue:

  • λ = 5: x = (1, 2, 1). Check: AᵀA(1, 2, 1) = (5, 10, 5).
  • λ = 2: x = (1, −1, 1). Check: AᵀA(1, −1, 1) = (2, −2, 2).
  • λ = 1: x = (1, 0, −1). Check: AᵀA(1, 0, −1) = (1, 0, −1).

AᵀA is symmetric and its eigenvalues are different, so these vectors are orthogonal. Divide each by its length:

u₁ = (1, 2, 1)/√6, u₂ = (1, −1, 1)/√3, u₃ = (1, 0, −1)/√2.

    | 1/√6   1/√3   1/√2 |            | 5  0  0 |
U = | 2/√6  −1/√3   0    |,       D = | 0  2  0 |
    | 1/√6   1/√3  −1/√2 |            | 0  0  1 |

Then UᵀU = I and Uᵀ(AᵀA)U = D. (Changing the sign of a column of U also works, and so does reordering the columns of U together with the diagonal of D.)

(3) For i = 1, 2, 3:

AAᵀvᵢ = AAᵀAuᵢ = A(AᵀAuᵢ) = A(λᵢuᵢ) = λᵢAuᵢ = λᵢvᵢ.

An eigenvector must also be nonzero. Here ‖vᵢ‖² = uᵢᵀAᵀAuᵢ = λᵢuᵢᵀuᵢ = λᵢ > 0, so vᵢ ≠ 0. So v₁, v₂, v₃ are eigenvectors of AAᵀ with eigenvalues 5, 2 and 1.

For v₄: AAᵀv₄ = A(Aᵀv₄) = A0 = 0 = 0 · v₄, and v₄ ≠ 0. So v₄ is an eigenvector of AAᵀ with eigenvalue 0.

Explicitly, v₁ = (4, 2√3, 1, 1)/√6, v₂ = (1, −√3, 1, 1)/√3 and v₃ = (0, 0, 1, −1)/√2. For v₄ = (a, b, c, d), Aᵀv₄ = 0 means a + c = 0, a + √3b = 0 and a + d = 0, so v₄ = (√3, −1, −√3, −√3), or any nonzero multiple of it.

(4) The four vectors are pairwise orthogonal:

  • For i ≠ j with i, j ≤ 3: vᵢᵀvⱼ = uᵢᵀAᵀAuⱼ = λⱼuᵢᵀuⱼ = 0.
  • For i ≤ 3: v₄ᵀvᵢ = v₄ᵀAuᵢ = (Aᵀv₄)ᵀuᵢ = 0.

Nonzero, pairwise orthogonal vectors are linearly independent. If c₁v₁ + c₂v₂ + c₃v₃ + c₄v₄ = 0, take the dot product with vⱼ: cⱼ‖vⱼ‖² = 0, so cⱼ = 0 for every j. Four linearly independent vectors in the 4-dimensional space ℝ⁴ form a basis.

(Another route: they are eigenvectors of AAᵀ for four different eigenvalues 5, 2, 1, 0, and eigenvectors for different eigenvalues are always linearly independent.)

Python check: with v₄ = (√3, −1, −√3, −√3), the matrix of dot products of v₁, ..., v₄ is diag(5, 2, 1, 10), and det(v₁ v₂ v₃ v₄) = 10 ≠ 0. The eigenvalues of AAᵀ are 5, 2, 1, 0.

In one or two sentences: If u is an eigenvector of AᵀA, then Au is an eigenvector of AAᵀ with the same eigenvalue, and the null space of Aᵀ adds the eigenvalue 0. The four vectors are orthogonal, so they form a basis of ℝ⁴, which is the idea behind the singular value decomposition.

Follow-ups (each builds on your last answer)

  1. Prof: "You said this is the idea behind the singular value decomposition. What are the singular values of A, and what does its decomposition look like?"
    You: "They're the square roots of the eigenvalues of A transpose A, so root 5, root 2 and 1. The lengths of v1, v2 and v3 are exactly those numbers, so dividing by them gives orthonormal vectors w1, w2, w3, and A is root 5 times w1 u1 transpose, plus root 2 times w2 u2 transpose, plus w3 u3 transpose. v4, scaled to length 1, only completes the w's to a basis of R4 when I want the full form with a 4 by 4 matrix on the left."
  2. Prof: "If you could keep only one of those three terms, which one, and how much of A would you lose?"
    You: "The largest one, root 5 times w1 u1 transpose. By the Eckart-Young theorem that's the best rank-1 approximation, and its squared error summed over all entries is the sum of the dropped squared singular values, 2 plus 1, so 3. The total is 8, the sum of the squared entries of A, which is also 5 plus 2 plus 1, so that one term keeps five eighths of it."
  3. Prof: "Keeping the largest singular values is the idea behind principal component analysis. Could that be useful on your own failure data?"
    You: "Possibly, as a first look, though I haven't tried it. I'd make a matrix with one row per input and one column per run, 1 for fail and 0 for pass. A strong second singular value would mean the runs split into groups that fail on different inputs, which the beta-binomial can't show, because it only counts how many runs fail on each input. Then I'd check whether a group matches something in the code, like using the helper the rule names."

Question 2: Maclaurin expansion in two variables and a limit

Let f(x, y) = eˣ log(1 + y), a function of two variables. Answer the following.

(1) Find the Maclaurin expansion of f(x, y) up to the terms of degree 3 (the Maclaurin polynomial of order 3).

(2) Find the constants a and b such that

lim over (x, y) → (0, 0) of [f(x, y) − y − x²/2 − xy] / (ax² + by²) = 1.

Answer.

(1) Multiply the one-variable series

eˣ = 1 + x + x²/2 + x³/6 + ..., log(1 + y) = y − y²/2 + y³/3 − ...

and keep every product of total degree 3 or less:

f(x, y) ≈ y + xy − y²/2 + (1/2)x²y − (1/2)xy² + (1/3)y³.

By degree: degree 1 is y; degree 2 is xy − y²/2; degree 3 is x²y/2 − xy²/2 + y³/3. There are no terms in x alone, because log(1 + 0) = 0.

(2) Subtract y + x²/2 + xy from the expansion:

f(x, y) − y − x²/2 − xy = −x²/2 − y²/2 + (terms of degree 3 and higher).

  • Along the x-axis (y = 0): f(x, 0) = 0, so the numerator is exactly −x²/2 and the ratio is (−1/2)/a. For the limit to be 1, a = −1/2.
  • Along the y-axis (x = 0): the numerator is log(1 + y) − y = −y²/2 + y³/3 − ..., so the ratio tends to (−1/2)/b. So b = −1/2.

With a = b = −1/2 the limit really is 1 from every direction. Write r² = x² + y². The denominator is −r²/2, and the numerator is −r²/2 + R, where the remainder R satisfies |R| ≤ Cr³ near the origin. So the ratio is 1 − 2R/r², and |2R/r²| ≤ 2Cr → 0.

So a = −1/2 and b = −1/2.

Python check: sympy gives the same expansion, and with a = b = −1/2 the ratio at distance 10⁻⁴ from the origin is within 0.00011 of 1 in all 72 directions tried (one every 5 degrees). The largest gap, about 0.000103, is near 120 degrees.

In one or two sentences: Multiply the series of eˣ and log(1 + y) and keep the terms up to degree 3. After removing y + x²/2 + xy, what is left near the origin is −(x² + y²)/2, so a = b = −1/2.

Follow-ups (each builds on your last answer)

  1. Prof: "You checked the x-axis and the y-axis first. Why isn't it enough to check every straight line through the origin?"
    You: "Because a function can tend to the same value along every line and still have no limit. The standard example is x squared y over x to the fourth plus y squared: along every line through the origin it goes to 0, but along the parabola y equals x squared it is always one half. That's why I bounded the remainder by C r cubed, which depends only on the distance r, not on the direction or the path."
  2. Prof: "Where does that C r cubed bound come from?"
    You: "From Taylor's theorem with remainder. The error after the degree-2 terms is one sixth of the third partial derivatives, taken at some point between the origin and (x, y), times x cubed, x squared y and so on. Those derivatives, like 2 e to the x over (1 plus y) cubed, are continuous, so near the origin they're bounded by some M. That makes the error at most M over 6 times (the size of x plus the size of y) cubed, which is at most a constant times r cubed."
  3. Prof: "Statisticians use only the first-order part of that expansion all the time. Where?"
    You: "In the delta method. If p hat is close to p, then g of p hat is about g of p plus g prime of p times the error, so its standard error is about g prime of p times that of p hat. For a 2-out-of-3 vote with independent runs, g is 3p squared minus 2p cubed and g prime is 6p times 1 minus p, which is 0.54 at p equal to 0.1, so the vote's estimate has about 0.54 times the standard error of p hat. The remainder we just bounded is why this needs p hat close to p, so it only holds with enough data."

Question 3: a probability density, its distribution function, and transformed variables

The random variable X has the probability density function

f_X(x) = c(1 − x²) for −1 < x < 1, and f_X(x) = 0 otherwise.

(1) Find the constant c and the cumulative distribution function F_X(x) = P(X ≤ x).

(2) Find E[X] and Var[X].

(3) The random variable Y is given by Y = e^X. Derive the probability density function f_Y(y) of Y.

(4) The random variable Z is given by Z = X². Derive the probability density function f_Z(z) of Z.

Answer.

(1) The total probability is 1:

c ∫₋₁¹ (1 − x²) dx = c(2 − 2/3) = 4c/3 = 1, so c = 3/4.

For −1 < x < 1:

F_X(x) = (3/4) ∫₋₁ˣ (1 − t²) dt = (3/4)[t − t³/3] from −1 to x = (3/4)(x − x³/3 + 2/3) = (2 + 3x − x³)/4.

So

  • F_X(x) = 0 for x ≤ −1,
  • F_X(x) = (2 + 3x − x³)/4 for −1 < x < 1,
  • F_X(x) = 1 for x ≥ 1.

Check: (2 − 3 + 1)/4 = 0 at x = −1, and (2 + 3 − 1)/4 = 1 at x = 1.

(2) The density is an even function, symmetric about 0, so E[X] = 0.

E[X²] = (3/4) ∫₋₁¹ (x² − x⁴) dx = (3/4)(2/3 − 2/5) = (3/4)(4/15) = 1/5.

Var[X] = E[X²] − (E[X])² = 1/5.

(3) y = eˣ is strictly increasing and maps (−1, 1) onto (1/e, e). The inverse is x = ln y, with dx/dy = 1/y. So

F_Y(y) = P(e^X ≤ y) = P(X ≤ ln y) = F_X(ln y),

and differentiating,

f_Y(y) = f_X(ln y) · (1/y) = 3(1 − (ln y)²) / (4y) for 1/e < y < e, and f_Y(y) = 0 otherwise.

(4) Z = X² takes values in [0, 1). For 0 < z < 1:

F_Z(z) = P(X² ≤ z) = P(−√z ≤ X ≤ √z) = F_X(√z) − F_X(−√z).

Differentiate, using d(√z)/dz = 1/(2√z):

f_Z(z) = [f_X(√z) + f_X(−√z)] · 1/(2√z) = 2 · (3/4)(1 − z) / (2√z) = 3(1 − z) / (4√z) for 0 < z < 1, and f_Z(z) = 0 otherwise.

Check: ∫₀¹ (3/4)(z^(−1/2) − z^(1/2)) dz = (3/4)(2 − 2/3) = 1.

Python check: both densities integrate to 1. A simulation of about 1.3 million draws of X gave mean 0.0001 and variance 0.2001, P(Z ≤ 1/4) = 0.6874 against the formula's 0.6875, and P(Y ≤ 1) = 0.5001 against 0.5.

In one or two sentences: c = 3/4 makes the density integrate to 1, the mean is 0 by symmetry and the variance is 1/5. For a new variable, write its distribution function through F_X and differentiate; for Z = X², both √z and −√z give the same z, so their densities add.

Follow-ups (each builds on your last answer)

  1. Prof: "You derived the density of Y = e to the X. What is E of Y, and do you really need that density to get it?"
    You: "No, I can integrate e to the x against the density of X directly. That's three quarters times the integral from minus 1 to 1 of (1 minus x squared) e to the x, and integrating by parts twice gives 4 over e for the integral. So E of Y is 3 over e, about 1.10."
  2. Prof: "Your 1.10 is bigger than e to the power E of X, which is 1. Is that a coincidence?"
    You: "No, it's Jensen's inequality: for a convex function g, E of g of X is at least g of E of X, with equality only when X is constant or g is a straight line over the values X can take. e to the x curves upward, so taking the average after the function gives more than applying the function to the average."
  3. Prof: "Where does Jensen's inequality matter in your plan?"
    You: "With the convex function theta squared, it says E of theta squared is at least p squared. E of theta squared is the chance that two runs from the same setting both fail on a random input, so they fail together at least as often as independence predicts, and equally often only when theta is the same on every input; that's Eckhardt and Lee's result. Runs from two different settings can do better, because then the extra term is the covariance of their two thetas, which can be negative if they find different inputs hard."

Question 4: confidence interval and hypothesis test for a mean (t distribution)

A car maker claims that one of its models runs at least 16 km on 1 litre of gasoline, on average. A sample of 10 cars was chosen, and each was driven on 1 litre of regular gasoline. The sample showed a mean of 17.2 km with a standard deviation of 1.5 km. Assume that the sample comes from a normal distribution whose mean μ and variance σ² are both unknown.

(1) Find a 95% confidence interval for μ.

(2) State the appropriate null hypothesis H₀. At the 5% significance level (α = 0.05), is the maker's claim correct?

(3) Describe how the result of the hypothesis test changes when the sample size increases.

Upper-tail values of Student's t distribution (the value t with P(T > t) = α):

Degrees of freedom α = 0.05 α = 0.025
9 1.833 2.262
10 1.812 2.228

(The English text of the original says "unknown standard deviation σ²"; the Japanese text says variance, which is what σ² means.)

Answer.

Use n = 10, x̄ = 17.2 and s = 1.5, taking s as the sample standard deviation with divisor n − 1. The degrees of freedom are n − 1 = 9, and the standard error is s/√n = 1.5/√10 = 0.4743.

(1) The 95% interval is x̄ ± t(0.025, 9) · s/√n = 17.2 ± 2.262 × 0.4743 = 17.2 ± 1.073.

So the 95% confidence interval for μ is about (16.13, 18.27) km per litre.

(2) The claim is μ ≥ 16. The test statistic is

t = (x̄ − 16) / (s/√n) = 1.2 / 0.4743 = 2.53.

Main answer: H₀: μ = 16 (standing for "μ ≤ 16", the case where the claim is not shown), against H₁: μ > 16, a one-sided test. Reject H₀ if t > t(0.05, 9) = 1.833. Here t = 2.53 > 1.833, so H₀ is rejected at the 5% level. The data support the maker's claim: the average is at least 16 km per litre, in fact above 16.

The other common form takes the claim itself as the null hypothesis: H₀: μ ≥ 16 (tested at μ = 16) against H₁: μ < 16. It rejects only if t < −1.833. Here t = +2.53, so H₀ is not rejected, and there is no evidence against the claim. Both forms reach the same conclusion, and the 95% interval in (1) also lies entirely above 16.

[CHECK] The original asks only for "the appropriate null hypothesis" and does not say which of the two forms it expects; both give the same conclusion. The answer also assumes that 1.5 km is the usual sample standard deviation with divisor n − 1. If it used divisor n, the standard error would be s/√(n − 1) = 0.5, t = 2.40 and the interval (16.07, 18.33), and the conclusions would not change.

(3) If the sample grows with the same mean and spread, the standard error s/√n shrinks and the t statistic grows like √n: t = 2.53 for n = 10, 3.58 for n = 20, 5.06 for n = 40 and 8.00 for n = 100. The critical value also falls toward the normal value 1.645. So the test rejects H₀: μ = 16 more and more clearly, the confidence interval gets narrower, and the power of the test rises. In general a larger sample makes even a small real difference from 16 significant, and if the true mean were below 16, a large sample would detect that too.

In one or two sentences: The mean is 1.2 km above 16 and the standard error is 0.47, so t = 2.53, beyond the one-sided 5% value 1.833, and the 95% interval (16.13, 18.27) lies above 16, so the claim holds. A bigger sample shrinks the standard error by √n and makes the conclusion stronger.

Follow-ups (each builds on your last answer)

  1. Prof: "You rejected at the 5 percent level. What is the p-value, roughly?"
    You: "It's the chance that a t variable with 9 degrees of freedom is above 2.53. The table here only shows it's below 0.025, because 2.53 is above 2.262, and a computer gives about 0.016. So if the true mean were exactly 16, a result this far above 16 would happen only about 1.6 percent of the time."
  2. Prof: "Suppose the maker tested ten models this way and advertised only this one, with p equal to 0.016. Would you still believe the claim?"
    You: "Less. If all ten models really averaged exactly 16, the chance that at least one gives p below 0.05 is 1 minus 0.95 to the power 10, about 40 percent. With a Bonferroni correction each model would need p below 0.005, and 0.016 doesn't pass that."
  3. Prof: "Your plan compares two file versions over about 10 tasks. How do you avoid the same problem there?"
    You: "The main question in RQ2 is one comparison: the effect of the file version, estimated in one mixed model over all tasks with task as a random effect, so I don't run ten separate tests. I do have two outcomes, the failure probability beyond the tests and the test pass rate, so I'd use Holm's method, a version of Bonferroni that is a little less strict, to keep the chance of any false finding at 5 percent. Results for single rules or single tasks I'd report as exploratory, not as confirmed findings."

Question 5: inclusion-exclusion and counting one-to-one maps

For a finite set X, |X| denotes the number of elements of X.

(1) For finite sets A₁, A₂, A₃, A₄, prove the following equation.

|A1 ∪ A2 ∪ A3 ∪ A4| =  |A1| + |A2| + |A3| + |A4|
                      − |A1 ∩ A2| − |A1 ∩ A3| − |A1 ∩ A4| − |A2 ∩ A3| − |A2 ∩ A4| − |A3 ∩ A4|
                      + |A1 ∩ A2 ∩ A3| + |A1 ∩ A2 ∩ A4| + |A1 ∩ A3 ∩ A4| + |A2 ∩ A3 ∩ A4|
                      − |A1 ∩ A2 ∩ A3 ∩ A4|

(You may use without proof the formulas for finite sets X₁, X₂, X₃: |X₁ ∪ X₂| = |X₁| + |X₂| − |X₁ ∩ X₂| and |X₁ ∪ X₂ ∪ X₃| = |X₁| + |X₂| + |X₃| − |X₁ ∩ X₂| − |X₁ ∩ X₃| − |X₂ ∩ X₃| + |X₁ ∩ X₂ ∩ X₃|.)

(2) Let A = {1, 2, 3, 4} and B = {1, 2, 3, 4, 5}. We want the number of one-to-one (injective) maps f: A → B that satisfy none of the following four conditions c₁, c₂, c₃, c₄:

c₁: f(1) = 2, c₂: f(2) = 3, c₃: f(3) = 2, c₄: f(4) = 4.

(2-1) Let S be the set of all one-to-one maps from A to B. Find |S|.

(2-2) For each i = 1, 2, 3, 4, let Cᵢ be the set of all one-to-one maps f: A → B that satisfy condition cᵢ. Find |C₁|.

(2-3) Find the following numbers: (a) |C₁ ∩ C₂|, (b) |C₁ ∩ C₃|, (c) |C₁ ∩ C₂ ∩ C₃|, (d) |C₁ ∩ C₂ ∩ C₄|.

(2-4) Find the number of one-to-one maps f: A → B that satisfy none of the four conditions c₁, c₂, c₃, c₄.

Answer.

(1) Let X = A₁ ∪ A₂ ∪ A₃. By the two-set formula,

|A₁ ∪ A₂ ∪ A₃ ∪ A₄| = |X ∪ A₄| = |X| + |A₄| − |X ∩ A₄|. (i)

By the three-set formula,

(1) H = Σ pᵢ log₂(1/pᵢ):

(2) Huffman's method: merge the two least likely items again and again. In sixteenths:

  1. s₁ (1) + s₄ (2) → {s₁, s₄} (3). Left: s₂ 4, s₃ 3, s₅ 4, s₆ 2, {s₁, s₄} 3.

  4. s₅ (4) + {s₃, s₆} (5) → {s₃, s₅, s₆} (9).
  5. {s₁, s₂, s₄} (7) + {s₃, s₅, s₆} (9) → root (16).

Label the two branches of each merge 0 and 1:

symbol probability code word length
s₁ 1/16 010 3
s₂ 4/16 00 2
s₃ 3/16 110 3
s₄ 2/16 011 3
s₅ 4/16 10 2

(3) Let the symbols of S have probabilities p₁, ..., p_q, and let the binary instantaneous code give them code words of lengths l₁, ..., l_q.

Step 1, the Kraft inequality: Σ 2^(−lᵢ) ≤ 1. An instantaneous code is prefix-free: no code word is the start of another. Place the code words as nodes in a full binary tree of depth L = max lᵢ. Code word i has 2^(L − lᵢ) descendants at depth L. Since no code word is a prefix of another, these sets of descendants do not overlap, and there are only 2^L nodes at depth L. So Σ 2^(L − lᵢ) ≤ 2^L, and dividing by 2^L gives Σ 2^(−lᵢ) ≤ 1.

Step 2. Use ln t ≤ t − 1 for t > 0 (with equality only at t = 1). Sum over the symbols with pᵢ > 0:

H(S) − L̄(S) = Σ pᵢ log₂(1/pᵢ) − Σ pᵢ lᵢ = Σ pᵢ log₂(2^(−lᵢ)/pᵢ) ≤ (1/ln 2) Σ pᵢ (2^(−lᵢ)/pᵢ − 1) = (1/ln 2) (Σ 2^(−lᵢ) − Σ pᵢ) ≤ (1/ln 2) (1 − 1) = 0.

So H(S) ≤ L̄(S). Equality holds exactly when pᵢ = 2^(−lᵢ) for every symbol.

(2) A grammar with one non-terminal S:

S → aSa | bSb | a | b | ε

Correctness has two directions.

  • Every generated string is a palindrome. By induction on the length of the derivation: ε, a and b are palindromes, and if u is a palindrome then so are aua and bub, because (xux)ᴿ = x uᴿ x = xux.
  • Every palindrome is generated. By induction on |w|. If |w| ≤ 1, then w is ε, a or b, each made by one rule. If |w| ≥ 2 and w = wᴿ, then the first and last letters are equal, so w = xux with x ∈ {a, b}. From xux = (xux)ᴿ = x uᴿ x we get u = uᴿ, so u is a shorter palindrome. By induction S ⇒∗ u, so S ⇒ xSx ⇒∗ xux = w.

(3) A grammar with non-terminals S and T:

S → aSa | bSb | aTb | bTa

T → aT | bT | ε

T generates every string in {a, b}∗.

  • Every generated string is not a palindrome. A derivation uses S → xSx some k ≥ 0 times and then S → aTb or S → bTa. So the string is w = x₁ ... xₖ c u d xₖ ... x₁ with c ≠ d and u any string. The letter in position k + 1 from the left is c, and the letter in position k + 1 from the right is d. In wᴿ, position k + 1 from the left holds d, so w ≠ wᴿ.
  • Every non-palindrome is generated. Let w ≠ wᴿ have length n. Compare w₁ with wₙ, w₂ with wₙ₋₁, and so on, and let position k + 1 be the first where w(k+1) ≠ w(n−k). This position is before the middle: a middle letter always equals itself, and if every pair before the middle matched, w would be a palindrome. The first k pairs match, so k uses of S → aSa or S → bSb produce them. The middle part w(k+1) ... w(n−k) starts and ends with different letters, so it is a u b or b u a, which S → aTb or S → bTa produces with T ⇒∗ u.

So L(G₃) = {a, b}∗ − L₂ = L₃.

(4) A short model answer:

  • The syntax of programming languages is written as a context-free grammar, usually in BNF or EBNF. Nested structures such as brackets, blocks and expressions cannot be described by regular expressions (finite automata), but a context-free grammar can describe them.
  • Compilers and interpreters build their parser from the grammar, often with a tool such as yacc or Bison (LR parsing) or by hand (LL, recursive descent). The parser checks the syntax and builds a parse tree or abstract syntax tree, which later stages use for type checking and code generation. As G₁ shows, the grammar can also fix operator precedence and associativity.
  • In theory, context-free languages are exactly the languages recognised by pushdown automata. Membership can be decided in O(n³) time for any context-free grammar (the CYK algorithm), and in linear time for the deterministic grammars used for programming languages.
  • Other uses: data formats such as XML and JSON, query languages, natural language processing, and, more recently, restricting the output of a language model to strings of a grammar (for example, valid JSON).

In one or two sentences: S → aSa | bSb | a | b | ε builds a palindrome from the middle outward. For non-palindromes, match equal letters on the outside and then force one mismatched pair, aTb or bTa, with anything inside.

Question 5: Laplace transforms

The Laplace transform of a function f(t) defined for real numbers t ≥ 0 is given by

L[f(t)] = F(s) = ∫₀^∞ f(t) e^(−st) dt,

where s is a complex number.

(1) Find the Laplace transform L[ρ(t)] of the unit ramp function ρ(t), where ρ(t) = t for t ≥ 0 and ρ(t) = 0 for t < 0.

(2) Derive L[df(t)/dt] = sF(s) − f(0).

(3) Find the Laplace transform L[f(t)] of the function f(t) = 3t² + 5t − 2.

Answer. Assume Re s > 0 and, in (2), that f(t)e^(−st) → 0 as t → ∞ (true when f grows at most exponentially and Re s is large enough).

(1) Integrate by parts with u = t and dv = e^(−st) dt:

L[ρ(t)] = ∫₀^∞ t e^(−st) dt = [−t e^(−st)/s] from 0 to ∞ + (1/s) ∫₀^∞ e^(−st) dt = 0 + (1/s)(1/s) = 1/s².

(For Re s > 0, t e^(−st) → 0 as t → ∞, and ∫₀^∞ e^(−st) dt = 1/s.)

(2) Integrate by parts with u = e^(−st) and dv = f′(t) dt:

L[f′(t)] = ∫₀^∞ f′(t) e^(−st) dt = [f(t) e^(−st)] from 0 to ∞ − ∫₀^∞ f(t) (−s e^(−st)) dt = (0 − f(0)) + s ∫₀^∞ f(t) e^(−st) dt = sF(s) − f(0).

(3) Use linearity with L[1] = 1/s, L[t] = 1/s² and L[t²] = 2/s³ (in general L[tⁿ] = n!/sⁿ⁺¹). L[t²] also follows from (2): for g(t) = t², g′(t) = 2t and g(0) = 0, so 2/s² = L[2t] = s L[t²], and L[t²] = 2/s³.

L[3t² + 5t − 2] = 3 · 2/s³ + 5/s² − 2/s = 6/s³ + 5/s² − 2/s = (−2s² + 5s + 6)/s³.
